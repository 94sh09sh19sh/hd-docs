    血液透析中心平板照護輔助系統 — 進度首頁¶

    本週定版：1007｜1014 修訂中

    每週三開會日定版一次。下方連結永遠指向現行版，網址不變；日期標的是它最後一次定版的週次。

    最近三週¶

    1014 — 規則引擎與護理紀錄完成，四條規則的門檻請醫師確認（迭代 17.8～18.1） · 修訂中¶

    進度：

    • 1009～1010 遊戲化寫成兩份其他文件，需求寫進 SRS（73 → 81 條），排成迭代 20～23
    • 1010 迭代 17.8：護理紀錄簽核後複製、貼進院內的正式紀錄（DART 預設、SOAP 可切），緊急回報的圖示畫出症狀本身；血壓圖加正常區間判斷不做
    • 1010 迭代 18：風險分層提示、療程中預警、劑量調整參考加上 Kt/V 趨勢推估，一律由固定規則計算、不經 AI，只在護理站專業版；書面確認沒登記之前真實病人一律不比對
    • 1010 迭代 18.1：書面確認閘門改放進系統管理；四條規則換成依指引與研究查的建議門檻，1014 請醫師確認；迭代 18 漏收的文件（進度報告、架構圖、測試手冊附錄）補齊

    1007 — 第二次進院部分成功，院方 API 取代手動輸入（迭代 15～17）¶

    進度：

    • 1001 第二次進院：B 級部分成功。服務在院內主機上起來、外殼 APK 建好，護理端登不進去（後端不放行護理端的來源）；部署手冊改寫成第十五冊，另寫之三（為什麼登不進去）、之四（主機位址改用 IP）
    • 1004～1005 讀了同院 IDH 系統的程式，使用者逐項決定：直接用院方透析清單 API、抽血數值暫定拿不到（相關功能預設關閉）、低血壓門檻與處置直接套用、主機位址改用 IP
    • 1005 新版需求，同日完成迭代 15～17：院方 API 判斷得出來的事不再要護理師做；病人平板中間改成血壓與脫水量的折線圖加一條跑馬燈；跑馬燈內容由 AI 寫、護理師只核准。規則引擎與管理儀表板順延為迭代 18、19
    • 1006 迭代 17.1：簡易版改成把病人拖到平板（每次透析配，床號由院方資料補）；平板停用移到系統管理；護理端改名「公告與院內衛教」「結束與離院衛教」；一條指令就看得到病人平板透析到一半的樣子
    • 1007 迭代 17.2～17.6：簡易版中間改成平板，把病人拖上去就配好、平板右上角自動出現床號，病人框多一顆重新整理、剛上機的病人排最上面；系統裡所有 AI 生成的內容禁用簡體字與中國大陸用語，查到就請 AI 重寫，最後一次仍不合格也照樣交出，畫面上看不出這道把關；病人平板加回病人姓名與現在時間（病歷號仍不上首頁）；透析一律以開始後四小時結束（院方規定，不管院方資料有沒有預計結束時間），病人平板、簡易版、專業版的進度與「待確認下機」都照這一條；簡易版公告與院內衛教的草稿可以換到後面幾則；專業版拿掉「病人」那一頁（病人一律由院方 API 建立），「裝置管理」改成「新增裝置」只管註冊新平板，解除佈建移到系統管理，排班與指派的病人選單與簡易版同一個順序、有重新整理
    • 1007 迭代 17.7：「護理師自己新增病人」做成開關、預設關閉，開了專業版排班與指派、簡易版病人框同時出現（院方資料缺人時的備援）；系統管理「平板停用」改叫「平板管理」；簡易版公告與院內衛教拖到平板就只在那台播，有病人配著就放得上（原本要有床號）；開發用的床號改成醫院的寫法（A1、A2…，沒有 4 號床）
    • 1007 待決事項有了答案：院內主機的 IP 是固定的（Q-27 第 12 題，第三次進院照換）；斷電後由護理長重新登入；所有護理師都可以核准跑馬燈內容；院方資料沒有預計結束時間時一律以四小時計。新增 Q-36（衛教要不要維持三種）、Q-37（護理紀錄現在是什麼形式、系統的記錄怎麼接上現有作業）；跑馬燈開啟前仍要請長者在床上看過速度

    0930 — 部署改為容器、介面極簡重設計（迭代 11～14.5）¶

    進度：

    • 0926 依第一次進院的教訓重排四件事：部署改為 Docker ＋ git clone、外殼 App 獨立 repo、AI 閘道、介面極簡，排成迭代 11～14；規則引擎與管理儀表板順延為迭代 15、16
    • 迭代 11～14 完成：開發機上從零部署、更新與回退各一次；外殼 APK 在主機上離線建置；病人端首頁只剩三區、護理端新增簡易版並設為預設
    • 迭代 14.1～14.5：凌晨畫面停在前一天、掃 QR code 佈建平板、簡易版修正；斷線示警遍及每一個畫面，大量求助湧入時專業版不再被橫幅蓋掉；醫師說透析室很暗，病人端改白底；平板確定 10 吋，橫放直放字一樣大
    • 部署手冊新增第十一～十四冊，第十四冊是第一次部署用的新手版；Q-32（對外連線）0930 已回覆，擋住第二次進院的剩 Q-27 未答的題（斷電重開誰登入、Docker Desktop 兩項設定）
