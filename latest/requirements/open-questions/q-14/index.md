# 尚待確認事項清冊 Q-14 醫院的勞動條件規定

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 5 章

|            |                            |
| ---------- | -------------------------- |
| **問誰**   | 護理部、人資               |
| **急迫度** | D                          |
| **卡住**   | 迭代 5 的 FR-M04（可暫代） |
| **狀態**   | 待提出                     |

**背景**

系統要協助排班，而**排班功能唯一的 P0 硬性要求是「不得產出違反規定的班表」**——違反時擋下儲存，不是提示而已。要做到這件事，得先知道規定是什麼。

**具體要問的**

1. 醫院對護理師的連續工時上限、兩班之間最短間隔、單日與單週時數上限，各是多少？
1. 這些規定是照勞基法，還是醫院另有更嚴格的內規？有沒有書面文件？
1. 有沒有特殊情況的例外（例如緊急支援、自願加班）？例外要不要留紀錄？
1. 夜班或連續夜班有沒有額外限制？
1. 違反時系統應該完全擋下，還是允許護理長以「已知悉」的方式覆寫？覆寫要不要留紀錄與理由？
1. 排班還有沒有其他硬性條件（例如每班至少要有一位資深護理師、特定技能的人力配置）？

**現況／暫代做法**

先以勞基法基本條件實作，**規則做成可設定**。院方規定到位後改設定即可。

**0911 已實作**：五條規則的數值存在 `operational_settings` 資料表，暫定值與依據如下——

| 規則                 | 暫定值  | 依據                                           |
| -------------------- | ------- | ---------------------------------------------- |
| 單一班次連續工時上限 | 12 小時 | 勞動基準法第 32 條                             |
| 兩班之間最短間隔     | 11 小時 | 勞動基準法第 34 條                             |
| 單日工時上限         | 12 小時 | 勞動基準法第 32 條                             |
| 連續七日工時上限     | 46 小時 | 第 30 條正常工時 40 小時＋第 32 條延長工時分攤 |
| 連續出勤日數上限     | 6 日    | 勞動基準法第 36 條（每七日至少一日例假）       |

每個數字在設定畫面上都帶著這個「依據」一起顯示，要改的人看得到它現在是誰說的。違反時**擋下儲存**並逐條說出違反哪一條、上限多少、這張班表會到多少；被擋下的嘗試也會寫入稽核軌跡。

第 5 題（能不能讓護理長以「已知悉」覆寫）**尚未實作，也刻意先不做**：SRS 5.3 把 FR-M04 列為本節唯一的 P0 硬性擋下項。要開這個口子，需要護理部明確表態，而且覆寫一定要留紀錄與理由——這是新增一條規則，不是放寬既有的。
