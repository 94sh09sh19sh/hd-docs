# 尚待確認事項清冊 Q-22 平板共用的消毒 SOP

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 5 章

|            |                            |
| ---------- | -------------------------- |
| **問誰**   | 感染管制室、護理部         |
| **急迫度** | D                          |
| **卡住**   | 非軟體範疇，但影響實際上線 |
| **狀態**   | 待提出                     |

**背景**

15 台平板共用是新的感染風險點。這不是軟體能解決的問題，但**它是上線的前提條件之一**，不能因為不屬於開發範圍就不追。

閒置輪播讓平板變成長時間顯示的公共資訊面板，觸碰頻率不會下降，消毒需求只增不減。

**具體要問的**

1. 平板的消毒 SOP 訂了嗎？多久消毒一次、用什麼消毒劑？
1. 消毒劑會不會傷到螢幕或觸控功能？要不要配保護貼或防水套？
1. 消毒動作要不要在系統上留紀錄？（可做成解除綁定時的一個確認步驟）
1. 免疫低下或帶菌病人的平板要不要專機專用？
1. 平板在病人之間交接時，誰負責消毒？護理師還是清潔人員？
