# 尚待確認事項清冊 Q-41 求助錄音的遮名、同意與台語詞庫

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 3 章

|            |                                                                                                                                                      |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **問誰**   | 院方（第 1 題，併 Q-06）；護理部、母計畫主持人（第 2 題）；護理部（第 3、4 題）                                                                      |
| **急迫度** | B                                                                                                                                                    |
| **卡住**   | 迭代 34、35 對真實病人錄音（SRS FR-P20、P21、N22、S20）；開發機上的實作與照腳本錄的語料驗證不受阻                                                    |
| **狀態**   | 待提出（1123 新增；《[緊急求助的語音說明](https://94sh09sh19sh.github.io/hd-docs/latest/notes/emergency-voice-help/index.md)》9.2 第 5、6、8、9 題） |

**背景**

- 1123 使用者把求助的錄音寫進需求（SRS 0.11）：「其他」按住說話、臨床組求助送出後錄床邊對話、轉寫後挑原句給護理師加進求助處置紀錄；語氣與推估的到床邊只存不顯示
- 1110 醫師答原音保留、之後訓練透析場景的台語語音模型，同意與研究用途醫師已說清楚；本題問的是落到流程上的細節
- 送到辨識端點的是可識別的原音，超出 Q-06 現在問的範圍

**具體要問的**

| #   | 問句                                                                             | 開發端建議                                                                                                                                                                                                                                                                    |
| --- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 逐字稿送 AI 挑句子前遮掉病人姓名，夠不夠？「阿英姨」這類稱呼遮不乾淨             | 遮姓名；AI 呼叫紀錄的提示內容不存逐字稿，只存「發生過、用哪個模型」                                                                                                                                                                                                           |
| 2   | 病人與護理人員的同意怎麼取得？同意書用哪一份、母計畫的倫理審查同意書要不要修訂？ | 病人書面同意、護理端登記（SRS FR-N22）；第一版只有錄音一格；護理人員另簽一次、由系統管理者登記；**1125 使用者定沒登記時不錄「整台」**：那一床此刻當班的負責護理師都登記了才錄，沒排到人也不錄（迭代 35 照這條做了）；同意書寫明原音、逐字稿與語氣留存，原音會用來訓練語音模型 |
| 3   | 病人常用的台語說法有哪些？                                                       | 請護理師補進詞庫（頭殼眩、欲吐、喘袂過、胸坎悶、畏寒、足疼、艱苦…）                                                                                                                                                                                                           |
| 4   | 「按不完三下的人也說不好話」對不對？                                             | 請護理部依現場經驗校正（之二第 1 節）                                                                                                                                                                                                                                         |

**現況／暫代做法**

迭代 33（一點送出與倒數）與錄音無關，不受這一題影響。34、35 在答覆前只在開發機做，語料由開發團隊、護理師、長者志工照腳本錄，不錄病人。34 的開發機部分 1124 做完、35 的 1125 做完：病人與護理人員的同意都做成護理端登記（病人在「排班與指派」、護理人員在系統管理），沒登記就不錄；第 1 題照建議做了（AI 閘道遮姓名、呼叫紀錄不存提示與輸出），院方答「不夠」再改。
