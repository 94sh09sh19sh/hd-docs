# 尚待確認事項清冊 Q-26 透析適足性的計算公式與輸入來源

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 5 章

|            |                                                      |
| ---------- | ---------------------------------------------------- |
| **問誰**   | 透析室醫師（公式）、資訊室（輸入來源）               |
| **急迫度** | D                                                    |
| **卡住**   | 迭代 4 的 FR-N07（已用暫定值實作）                   |
| **狀態**   | 待提出。**1005**：BUN 暫定拿不到，透析適足性預設關閉 |

**背景**

FR-N07 的 URR 與 Kt/V 計算，開發端先採用常見的 Daugirdas 第二代單池公式（spKt/V），輸入為透析前後 BUN、結束體重、實際脫水量、透析時間。

**具體要問的**

1. 院內慣用的是哪一個公式（單池 spKt/V、平衡 eKt/V，或其他）？
1. 透析後抽血的時間點有沒有院內規定？會影響要不要做校正。
1. 這五個輸入值目前放在院方的哪個系統？能不能跟輪播第三層的數值一起由院方提供（Q-09）？
1. 院方已經有算好的 Kt/V 時，要以院方的為準，還是兩者並列？（目前並列、分開呈現）

**現況／暫代做法**

每一筆結果都記下公式版本（`DAUGIRDAS2-SPKTV-v1`），換公式時新結果用新版本，舊結果不改。畫面只呈現數值與趨勢，不標示目標值，也不做預測（預測屬迭代 7）。

**1004 線索（同院 IDH 系統程式，不是院方答覆）**：第 3 題的五個輸入值，有三個在同院系統用的透析清單 API 裡——結束體重（「結束體重」欄）、實際脫水量（單位公升，本系統要換成 mL）、透析時間（由開始與結束時間算出）。**透析前後 BUN 不在**，那支 API 沒有任何抽血數值，Kt/V 也就算不出來。第 3 題因此縮小成「BUN 存在哪個系統」，與 Q-09 第 11 題一起問。見《[同院 IDH 系統參考調查](https://94sh09sh19sh.github.io/hd-docs/latest/notes/idh-reference-survey/#3-51-%E5%80%8B%E6%AC%84%E4%BD%8D%E8%88%87%E6%9C%AC%E7%B3%BB%E7%B5%B1%E7%9A%84%E5%B0%8D%E6%87%89)》第 3 節。

**1005 使用者決定**：透析前後 BUN 暫定拿不到。透析適足性收進功能開關「需要抽血數值的功能」，**預設關閉**，關閉時護理端「病人趨勢」不出現適足性那一張卡、後端端點一併擋下；**開啟條件**是院方提供透析前後 BUN 的來源。第 3 題因此暫停；第 1、2、4 題（公式、抽血時間點、院方 Kt/V 怎麼並列）等到要開啟時再問醫師。
