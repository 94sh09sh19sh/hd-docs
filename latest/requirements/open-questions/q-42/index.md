# 尚待確認事項清冊 Q-42 護理師回饋的管道與聯絡人

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 4 章

|            |                                                                                                                                                                                   |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **問誰**   | 透析室醫師（第 2 題經醫師轉問護理長）                                                                                                                                             |
| **急迫度** | **C**                                                                                                                                                                             |
| **卡住**   | 首波試用開始時收不收得到回饋：外部表單要不要建、紙卡要不要印、聯絡人是誰；第 3 題卡問卷能不能用在論文                                                                             |
| **狀態**   | **部分已回覆（1125）**：第 1～4 題開會答；剩 1125 新增的第 5～7 題（《[護理師回饋](https://94sh09sh19sh.github.io/hd-docs/latest/notes/nurse-feedback-plan/index.md)》第 8.2 節） |

**背景**

- 使用者要收到護理師對本系統的評價與修正建議；護理師不回饋的主因是沒時間、說了沒用、怕得罪人、想到時不在電腦前
- 建議的主管道在系統外：護理站 QR code 連外部短表單（零開發），紙卡備援，種子護理師每週彙整，試用第 2、4 週 SUS 短問卷，進院跟班觀察；系統內意見入口（SRS FR-N23）是候選

**具體要問的**

| #   | 問句                                                                                                      | 選項                                                                       | 開發端建議                               |
| --- | --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------- |
| 1   | 回饋管道用哪些？                                                                                          | 甲：外部短表單＋紙卡／乙：只用紙卡／丙：再加系統內按鈕（要排迭代、晚幾週） | 甲；表單不收病人資料，護理師用自己手機填 |
| 2   | 聯絡人是誰？                                                                                              | 甲：請護理長指定一位種子護理師／乙：護理長本人／丙：只靠醫師轉達           | 甲                                       |
| 3   | 回饋與問卷要不要用在論文或計畫成果？                                                                      | 甲：要（問卷與訪談可能要先送審，量表用正式版）／乙：不要，只用來改系統     | 先問清楚；若甲，第 2 週問卷前要辦好      |
| 4   | 下一次進院能不能跟班觀察 30 分鐘、訪談 2～3 位護理師？                                                    | 甲：可以／乙：不行，只用表單                                               | 甲                                       |
| 5   | （1125 新增）護理站電腦的瀏覽器開不開得了外部表單？                                                       | 表單建好後，請醫師或護理師在護理站電腦點一次網址                           | 開不了的話紙卡改成主管道、迭代 36 不做   |
| 6   | （1125 新增）要用在論文的問卷、訪談、跟班紀錄送倫理審查，要不要與錄音同意書（Q-41）併成母計畫同一次修正？ | 甲：併成一次／乙：分開送                                                   | 甲                                       |
| 7   | （1125 新增）紙卡誰收？                                                                                   | 甲：醫師每週三開會前拍一次意見箱的照片／乙：開發端進院時才收               | 甲                                       |

**1125 開會答覆**：

| 題      | 答覆                                                                               | 對本系統                                                                                                                                                                                                                                                      |
| ------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 第 1 題 | 護理師上班不能用手機；醫師建議系統放表單連結，比掃 QR code 成本低                  | QR code 不用；護理端導覽列多一項「意見」開外部表單，網址由系統管理者填，排成**迭代 36**（SRS FR-N23 第一段、實作規格書 4.36），1125 使用者開口、同日做完。**紙卡併行**（開發端判斷，《護理師回饋》4.4）：連結要等換版、護理站電腦未必開得了、共用電腦不夠匿名 |
| 第 2 題 | 聯絡人目前是醫師；要頻繁聯絡再指定護理師，指定一位會加重那一位的工作、降低參與意願 | 種子護理師不做；紙卡誰收改成第 7 題                                                                                                                                                                                                                           |
| 第 3 題 | 甲：要用在論文                                                                     | 問卷、訪談、跟班紀錄核准後才收研究用的；核准前收的只用來改系統（《護理師回饋》8.1）；送審方式是第 6 題                                                                                                                                                        |
| 第 4 題 | 看當天情況                                                                         | 進院時現場不忙才做，不另外約                                                                                                                                                                                                                                  |

**現況／暫代做法**

表單照第 1 題建，網址等院內換到含迭代 36（1125 做完）的 tag 後由系統管理者填；紙卡照印。醫師每週三開會轉達照舊。
