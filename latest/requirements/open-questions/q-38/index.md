# 尚待確認事項清冊 Q-38 要不要立案建立本院透析病人的認知遊戲參考值

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 4 章

|            |                                                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| **問誰**   | 透析室醫師                                                                                                        |
| **急迫度** | **C**                                                                                                             |
| **卡住**   | 連點成畫（遊戲化之五）對真實病人收資料之前：要不要先過倫理審查、取研究同意、多記分層變項。程式第 1 次迭代可以照做 |
| **狀態**   | 待提出（1026 新增；**排定 1102 那週問醫師**）                                                                     |

**背景**

- 1026 使用者定：連點成畫全程不走需要香港方面同意的路線，B 部分（圓方交替）因此**沒有任何外部常模**，只能跟病人自己比
- A 部分有公開常模（Tombaugh 2004），但那是北美、紙本、沒在透析、要求盡快的條件；本系統是平板、透析中、不說盡快，偏差方向相反、大小不明（之五第 5 節）
- 之五第 5 節原本就寫「院內累積到足夠人數後建本院參考值、要先過倫理審查」，但沒有人負責、沒有計畫，也沒排時間

**開發端建議：要立案**

| #   | 理由                                                                                                        |
| --- | ----------------------------------------------------------------------------------------------------------- |
| 1   | B 部分與 B−A 唯一能有 benchmark 的辦法                                                                      |
| 2   | 施測條件與參考值完全一致，之五第 5 節的五項偏差一次消掉                                                     |
| 3   | 遊戲本來就會記完成時間、點錯、施測時點（之五第 3.3 節），多出來的主要是倫理審查與同意書，不增加護理師的工作 |
| 4   | 時間性：研究同意要在收資料**之前**取得；第 1 次迭代上線才決定，前期的資料只能另外申請回溯使用               |

限制要先講清楚：

- 這是「本院透析病人」的參考值，回答的是「跟其他透析病人比」，**不是**「跟健康的同齡人比」；不能拿來判斷認知是否受損
- 單一院區的人數可能不夠細分年齡與教育程度，要先估人數（Q-34 的床位數），不夠就分層放粗，或找其他院區合作

**具體要問的**

| #   | 問句                                                                                                                  |
| --- | --------------------------------------------------------------------------------------------------------------------- |
| 1   | 要不要立案？計畫主持人由誰擔任、要不要掛在母計畫底下？                                                                |
| 2   | 倫理審查走哪一種（一般或簡易）？研究同意書由誰向病人說明與取得（社工、護理師或研究助理）？                            |
| 3   | 分層要用哪些變項：年齡、教育程度，還要不要透析年資、糖尿病？教育程度從病歷取還是病人自填？                            |
| 4   | 本院透析病人大約多少人？每一層要多少人才算數？不夠的話要不要找其他院區？                                              |
| 5   | 要不要另外收一個臨床效標（例如由專人施測的 MoCA），用來驗證連點成畫量到的是認知？這要人力，不做的話參考值只能描述分布 |
| 6   | 要不要在透析前或非透析日也測一次，量出透析中施測的偏差有多大？                                                        |

**現況／暫代做法**

照之五現行設計：A、B 都跟自己比，A 部分另附外部常模的參考對照（第 3 次迭代、受 FR-R08 閘門）。答覆是「要立案」的話，倫理審查通過前，連點成畫的資料只用於照護、不用於研究；分層變項（第 3 題）在第 1 次迭代的資料表先留欄位。答覆是「不立案」的話，之五第 5 節那一句改成「不建本院參考值」，其餘不動。
