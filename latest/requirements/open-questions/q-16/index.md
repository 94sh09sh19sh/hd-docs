# 尚待確認事項清冊 Q-16 護理師工作 ID 格式

上層文件：《[尚待確認事項清冊](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/open-questions/index.md)》第 5 章

|            |                          |
| ---------- | ------------------------ |
| **問誰**   | 資訊室、護理部           |
| **急迫度** | D                        |
| **卡住**   | 註冊時的驗證規則         |
| **狀態**   | 已提出（0909），尚未回覆 |

**背景**

護理端以「工作 ID」（醫院員工編號）註冊。目前系統接受英數字 3～32 字元，沒有格式驗證。

**具體要問的**

1. 醫院員工編號有沒有固定格式？長度、前綴、英數規則？
1. 離職再任職的人，員工編號會沿用還是換新？（影響帳號是否可重複使用）
1. 支援人力或實習生有沒有員工編號？他們需不需要用這套系統？
1. 系統要不要跟醫院的人事資料對照驗證，還是自行維護即可？

**現況／暫代做法**

沿用 0909 的寬鬆規則（英數字 3～32 字元）。格式確認後加上驗證即可，不影響既有資料。
