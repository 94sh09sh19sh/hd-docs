上層文件：《[軟體需求規格書](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/srs/index.md)》第 5 章

## 摘要

- 涵蓋 FR-N01～N23，表格欄位為編號、描述、優先權、SaMD 風險、0910 異動
- 通報與總覽：N01 排班與裝置指派、N02 即時總覽、N03 緊急通報（1015 起附床邊前速覽、看與接分開）、N11 近期再發標示、N12 常駐總覽螢幕
- 求助處理與紀錄：N10 結案結構化登記（1015 起結案自動建「求助處置」草稿）、N04 與 N05 護理紀錄草稿、N18 紀錄格式 DART（預設）或 SOAP、複製貼上交給院內系統（1010）
- 高風險：N06 抽血與 Hb／EPO 趨勢、N13 輸出逐則標記已檢視與是否採納、N21 認知遊戲常模對照（1026 新增，受 FR-R01～R08 約束）；N07 Kt/V 預設關閉、N08 心理社會彙總、N09 SOP 查詢
- 介面：N14～N16 簡易版與專業版、單一工作台、一步完成（1007 改以平板為中心）；N17 跑馬燈內容由 AI 生成、護理師核准
- 1010 遊戲化相關：N19 被聽見的回覆、N20 遊戲資料狀態評估彙整（只陳述事實、只跟本人比）
- 1123～1125：N22 錄音同意登記、N23 意見入口（第一段表單連結 1125 完成，系統內完整表單仍為候選）
- 補充說明含 N10 欄位與「確認時間／到達床邊時間」分開記錄、簡易版各任務一步做法表、1015 床邊前速覽的內容與排除內容、N17 草稿來源、DART 與 SOAP 段落對照

| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 處理方式       | 分類清單（現場處置、通知醫師、調整機台設定、提供物品、協助如廁、心理安撫、轉介、其他）                                                                                |
| 處理結果       | 分類清單（已解決、部分緩解、持續觀察、升級處理、病人自行取消、無法處理）                                                                                              |
| 是否需後續追蹤 | 是／否，若是則帶出追蹤事項                                                                                                                                            |
| 到達床邊時間   | 由護理師在床邊登記產生，**與「確認通報」的時間分開記錄**。**0919：此登記需要護理師隨身帶著裝置，首波試用期間關閉**（見 FR-S11），關閉期間該欄位留空而非以確認時間頂替 |
| 自由文字補充   | 選填，不取代上述結構化欄位                                                                                                                                            |

**為什麼「確認時間」與「到達床邊時間」要分開**：兩者的差距是資料品質的檢查點。若只記錄確認時間，一旦這個數字被用於績效，最省力的做法會變成「先按確認再慢慢走過去」，指標就失去意義。分開記錄讓這種情況看得見。

**0919：這一條暫時做不到，而且必須承認做不到。** 護理站只有一兩台桌機、護理師手上沒有平板，「到床邊才按」在物理上無法發生；硬留著這顆按鈕，得到的會是「回到護理站後補按」的假資料，比沒有資料更糟。因此首波試用期間**關閉這顆按鈕**，該欄位一律留空，並在成效指標中明確標示「本期間無到達時間資料」。等護理師手上有裝置時，在系統設定開啟即可，資料結構不必改。

**處理方式與處理結果的選項內容**：0919 起改由附錄 C 的預設清單提供，院方已授權採用，並可在護理端系統設定增刪改。

|                  | O 客觀       | 院方量測（每一筆附時間）；範本裡屬於「觀察」的勾選                                                                                                                                                       |
