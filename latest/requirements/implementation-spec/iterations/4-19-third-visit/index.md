# 實作規格書 4.19 第三次進院（1005 新增）

上層文件：《[實作規格書](https://94sh09sh19sh.github.io/hd-docs/latest/requirements/implementation-spec/index.md)》第 4 章

**目標**：護理站的電腦登得進護理端——1001 卡在這裡（部署手冊[第二次進院紀錄之一](https://94sh09sh19sh.github.io/hd-docs/latest/deployment/record-2-1001-login/index.md)）；同時把主機位址從名稱換成 IP，並探測一次院方 API。

**1005 使用者決定：主機位址改用 IP。** 換法照部署手冊[《護理站登不進去與主機位址之一》](https://94sh09sh19sh.github.io/hd-docs/latest/deployment/ref-login-switch-ip/index.md)。平板一台都還沒佈建，現在換代價最小；**前提是資訊室把那個 IP 固定下來**（Q-27 第 12 題），IP 會變就不要換。**1007 答覆：IP 是固定的**，前提成立。
