### 2. 那 3 次目標脫水量是護理師填錯，照醫師建議改成不擋

| 看什麼       | 結論                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 醫師說明     | 院方資料的數值有些是護理師填的，1116 那 3 次（最大 74.6 公升）就是護理師填錯                                                                                 |
| 醫師建議     | 不要擋：平板顯示錯的值，病人看到也會提醒護理師更正                                                                                                           |

| 現在         | **1124 程式改好**（開發機驗過：目標脫水量 74.6 公升照樣顯示，負數只擋那一個值）；換版之後院內才生效，之前照舊不採用那幾次的四個值                            |

### 3. 四小時照病人上機時間算，與系統現在的做法相同

| 看什麼           | 結論                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| 醫師答覆         | 四小時從病人上機開始算；病人可能遲到，但不會太誇張                                                      |
| 系統             | 現在就是「開始後四小時」，不必改；遲到不誇張，也就不會有跨過午夜的透析                                  |
| 請醫師或護理長答 | 下機是護理師手動下機，還是機器到時間自動下機（1118 沒問到）；影響系統提示「待確認下機」的時機，不擋首波 |

### 5. 求助的錄音、AI 推論端點、護理師回饋寫進規格，程式都還沒改

| 看什麼         | 結論                                                                                                                                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 求助一點就送出 | 病人點一個類別就送出、急迫度送出後可改；沒選的話 8 秒後自動送出「病人還沒選」、當緊急處理。跟錄音無關，可以先做                                                                                                                                               |

| 護理師回饋     | 主管道在系統外：護理站貼 QR code 連短表單、紙卡備援；系統內的意見按鈕先不做，試用一個月後看表單收得如何                                                                                                                                                       |
| 請醫師答       | 回饋用哪些管道、聯絡人是誰、要不要用在論文、下次進院能否跟班觀察 30 分鐘；錄音的同意書怎麼取得                                                                                                                                                                |
