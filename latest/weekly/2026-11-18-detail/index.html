    1.1 下一次進院改成同一趟做完三件事¶

    1111 開會改了目標：同一趟把透析清單抓取腳本跑起來、本系統換版、實際上線（首波試用）；之前是只做腳本、本系統等腳本穩定之後再換。順序與停手條件在《第五次進院任務二之三》第 0.3 節；腳本這一段照第四次進院與《院方 API 介接之四》。1116 現場照第五次進院的兩個任務做：抓取腳本照第五次進院任務一（簡易版）／之一（詳細版），本系統照第五次進院任務二／之一。

    順序 做什麼 沒做成的話
    1 透析清單抓取腳本：第四次進院 B-16～B-19（跑一輪、裝排程、看三輪、教學長） 本系統不換版
