    3.1 週一進院前（W）¶

    # 問題 答覆
    W-1 醫師帳號的 OneDrive 有沒有在同步 API_Fetch 那個資料夾？有的話，是搬到不同步的位置（學長與 APP 組都要改路徑），還是醫師同意留在 OneDrive？ 1108 學長「不確定，現場看」。1109 現場：OneDrive 有在執行，但同步的根目錄是 D 槽另一個資料夾；指定資料夾不在同步範圍，檔案屬性只有 Archive。沒有在同步，不必搬、不必問醫師（第十九冊之二 BR-09）
    W-3 主機上的 Python 是哪一版、誰裝的、可以用嗎？ 1108 學長「不確定，現場看」。1109 現場：py 有 Python 3.13，可以用；python 指令是 Microsoft Store 的空殼。誰裝的沒問
    W-4 歷史 txt 轉 UTF-8 由誰轉、什麼時候轉？開發端週一現場轉（先把原檔整份備份）可以嗎？ 1108 學長「可以先轉檔」。1109 現場：24 個月份檔（2024-12～2026-11）全已是 UTF-8，要轉 0 個，不必轉
    W-5 「發現有重複的資料就不放入」是指 ①整包跟上一段一樣就不附加；②逐列比對、只附加新的或有變的列；還是 ③匯進 IDH 資料庫時跳過重複？ 1108 學長：②，「同一個病患的上一筆跟當前打入的資料一樣的話就不寫入」。hd-hospital-fetch v0.1.0 照做

    A-2 新腳本要接著寫已經搬過去的那幾個月份檔，還是從新的檔名或子資料夾開始？ 1108 學長：接著寫，沿用 YYYY-MM.txt
    A-3 已經搬過去的歷史 txt 是哪一版腳本寫的？知道是什麼編碼嗎？ 1109 現場量：全是 UTF-8。哪一版寫的沒問；每段 3 行、本腳本 2 行的格式差異改問《之二》K-3
    B-1 IDH 丟掉床位以數字開頭的列，是刻意的嗎？ 1108 學長：那是 IDH 系統留下來的做法，能直接用 .txt 就好 → 本系統照收
    B-3 新腳本如果要寫 temp.csv，還要照原本丟這兩種列嗎？ 1108：不寫 temp.csv（C-14），這題不適用

    # 問題 答覆
    W-2 醫師的帳號平常一直登入著嗎？主機重開後會自動登入嗎？ 已知的事：主機只有一個 Windows 帳號；預設不關機；重開機後要輸入 Windows 登入密碼，登入後就是最高權限。排程照舊設「只在使用者登入時執行」、不經手密碼；重開機到有人登入之間停抓，狀態檔與本系統的過期示警看得到
    A-4 APP 組怎麼讀：多久讀一次、用什麼程式讀、讀的時候會不會一直開著檔、會不會把讀過的檔搬走或刪掉？ 使用者與 APP 組確認過：怎麼讀還在討論，暫定跟本系統一樣讀檔、一週一次（時間未定）；讀完就關，不搬、不刪。確切何時讀、讀多久之後找 APP 組確認，不問學長
