# 緊急求助的語音說明之五：「按住說話」的錄音腳本

版本：v0.1　文件狀態：規劃中（2026-11-24 開立）　適用讀者：幫忙錄音的人、FDE 工程團隊

上層文件：《[緊急求助的語音說明：根本判斷與設計](https://94sh09sh19sh.github.io/hd-docs/latest/notes/emergency-voice-help/index.md)》第 6 節；用在《[迭代 34 分冊](https://94sh09sh19sh.github.io/hd-docs/latest/testing/iteration-34/index.md)》`ar19`

## 摘要

- 用途：測語音辨識在實驗室 3090 上聽不聽得懂病人在「其他」按住說話講的內容；**不用病人的錄音**，請開發團隊與親友照這份腳本錄
- 台語一份（第 2 節，37 個檔，約 30 分鐘）、華語一份（第 3 節，30 個檔，約 25 分鐘）
- 用手機內建的錄音 App 就好，一句一個檔，檔名改成編號
- 意思對就好，用自己平常的講法，不必照字念；句子裡的症狀詞盡量講出來
- 背景的透析機聲、警報、鄰床說話由開發團隊事後混進去，錄的地方安靜就好
- 錄完把整批檔案交回給請你錄音的人

## 1. 給錄音的人：怎麼錄

**用途**：這些錄音只用來測一套透析室平板系統聽不聽得懂病人說的話，不公開，也不會放到程式碼裡。請不要在錄音裡講自己的名字、地址、電話或任何病歷資料。

**準備**

- 手機內建錄音 App：iPhone 用「語音備忘錄」，Android 用「錄音機」
- 安靜的房間，關掉電視與音樂；冷氣、電扇開著沒關係
- 坐著，手機平放在桌上、麥克風朝自己，不要拿在手上
- 距離用尺量一次：嘴巴到手機 **50 公分**（第 2 節的 A、C、D、E、S 組）或 **100 公分**（B 組）

**每一句這樣錄**

1. 按下錄音，停一秒
1. 講那一句（一次就好，不要連講兩次）
1. 停一秒，按停止
1. 檔名改成那一句的編號，例如 `T-A01`；不方便改檔名就**照表格順序錄、不要跳句**
1. 講錯、咳嗽、被打斷：把那個檔刪掉重錄

**講法**

- 表格的「意思」照你平常怎麼講就怎麼講，不必一字不差；「參考說法」只是參考
- 每一句都在 30 秒以內，大部分幾秒就講完
- C 組要小聲、有氣無力，像很不舒服的時候；D 組邊喘邊說，像剛走完樓梯

## 2. 台語（37 個檔，約 30 分鐘）

### A 組：平常音量，手機放 50 公分

| 編號  | 意思                 | 台語參考說法         |
| ----- | -------------------- | -------------------- |
| T-A01 | 我頭很暈             | 我頭殼眩眩           |
| T-A02 | 我想吐               | 我欲吐               |
| T-A03 | 我喘不過氣           | 我喘袂過來           |
| T-A04 | 我胸口悶悶的         | 我胸坎悶悶           |
| T-A05 | 我很冷，一直發抖     | 我畏寒，一直咇咇掣   |
| T-A06 | 打針的地方很痛       | 拍針的所在足疼       |
| T-A07 | 我的腳抽筋           | 我的跤咧抽筋         |
| T-A08 | 我很不舒服，全身沒力 | 我足艱苦，規身軀無力 |
| T-A09 | 我想要上廁所         | 我欲去便所           |
| T-A10 | 我肚子痛             | 我腹肚疼             |

### B 組：同樣 10 句，手機改放 100 公分

編號 `T-B01`～`T-B10`，內容與 A 組的 01～10 一樣（`T-B01` 講「我頭很暈」，依此類推），平常音量。

### C 組：小聲、有氣無力，手機放 50 公分

| 編號  | 講哪一句                     |
| ----- | ---------------------------- |
| T-C01 | 同 A01：我頭很暈             |
| T-C02 | 同 A02：我想吐               |
| T-C03 | 同 A03：我喘不過氣           |
| T-C04 | 同 A06：打針的地方很痛       |
| T-C05 | 同 A08：我很不舒服，全身沒力 |

### D 組：邊喘邊說，手機放 50 公分

| 編號  | 講哪一句                     |
| ----- | ---------------------------- |
| T-D01 | 同 A01：我頭很暈             |
| T-D02 | 同 A03：我喘不過氣           |
| T-D03 | 同 A04：我胸口悶悶的         |
| T-D04 | 同 A08：我很不舒服，全身沒力 |
| T-D05 | 同 A10：我肚子痛             |

### E 組：台語華語混著講，手機放 50 公分

照你平常會混著講的方式講，下面只是例子。

| 編號  | 意思                       | 混講的例子                 |
| ----- | -------------------------- | -------------------------- |
| T-E01 | 我頭暈，想吐               | 我頭殼眩眩，想要吐         |
| T-E02 | 護理師，我胸口很悶         | 護理師，我胸口足悶         |
| T-E03 | 我的手打針那邊很痛         | 我的手，打針那邊足疼       |
| T-E04 | 我想上廁所，可以幫我一下嗎 | 我欲去廁所，可以幫我一下嗎 |
| T-E05 | 我很不舒服，想躺一下       | 我感覺足艱苦，想要躺一下   |

### S 組：不講話，手機放 50 公分

| 編號  | 怎麼錄                                                |
| ----- | ----------------------------------------------------- |
| T-S01 | 按下錄音後完全不講話，10 秒後按停止                   |
| T-S02 | 按下錄音後不講話，輕輕敲桌子、翻幾張紙，10 秒後按停止 |

## 3. 華語（30 個檔，約 25 分鐘）

準備與錄法同第 1 節，檔名開頭改成 `M`。

| 組  | 編號         | 內容                                                                                 | 距離與講法              |
| --- | ------------ | ------------------------------------------------------------------------------------ | ----------------------- |
| A   | M-A01～M-A10 | 第 2 節 A 組的「意思」那一欄，用華語講；A04 講「我胸悶」、A05 講「我畏寒，一直發抖」 | 50 公分，平常音量       |
| B   | M-B01～M-B10 | 同 M-A01～M-A10                                                                      | 100 公分，平常音量      |
| C   | M-C01～M-C05 | 同第 2 節 C 組那五句，用華語講                                                       | 50 公分，小聲、有氣無力 |
| D   | M-D01～M-D05 | 同第 2 節 D 組那五句，用華語講                                                       | 50 公分，邊喘邊說       |

華語不錄 E 組與 S 組（台語那份已經錄過）。

## 4. 開發團隊：收到之後

- 檔案放在開發機的專案目錄以外，**不進 repo**；轉成 16 kHz、單聲道、16 位元 PCM 後經語音閘道送辨識端點
- 混入背景聲（透析機、鄰床說話、機器警報）另做一份，原檔不改
- 照 `ar19` 記：台語與華語分開，S 組與靜音段生出句子的次數（必須是 0）、詞庫用語有沒有出現、每一句從送出到字出現幾秒
- 這份腳本只涵蓋上層文件第 3.2 節的「其他」按住說話；床邊對話（護理師回應、兩種到床邊情形）的腳本之後另寫
