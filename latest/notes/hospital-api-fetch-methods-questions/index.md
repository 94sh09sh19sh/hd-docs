## 已確定，不必再問

| 事       | 結論                                                                         |
| -------- | ---------------------------------------------------------------------------- |
| 醫師授權 | 上週開會醫師明確表示：API 相關事宜授權學長決定                               |
| 哪台主機 | 本系統的部署主機就是學長說的那台：現場三台中最右邊那台                       |
| 介接方式 | 照學長：獨立腳本固定頻率抓、存到指定位置；本系統之後改讀檔，不自己打院方 API |
| 時程     | 1109（一）15:30 左右進院；週一只放腳本，本系統的讀檔模式排第二次進院         |

## 要問的（週一前最好有答案的排前面）

| #   | 問題                                                                                                                                       | 為什麼要問                                                                       | 之一的編號 |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ---------- |
| 1   | 指定資料夾在 OneDrive 底下，那台電腦的 OneDrive 有在同步嗎？有的話可以換到不同步的位置嗎？                                                 | 留底是全中心病人的姓名、病歷號明文，同步就離開醫院；有在同步，週一停在放腳本之前 | U-7        |
| 2   | 「跟原本的 `.py` 一樣存」是指成大版的 `YYYY-MM.txt`、一次兩行（`Date:`＋JSON）嗎？`temp.csv` 要不要寫？                                    | 決定腳本的輸出，APP 組與本系統都照這個讀                                         | U-5        |
| 3   | 已搬過去的歷史 txt 是哪一版腳本寫的？知道編碼嗎？                                                                                          | 新腳本要接著寫同一批檔，格式與編碼不能不一樣；週一也會在現場量                   | U-6        |
| 4   | 新腳本放在主機哪個資料夾？之後由誰維護、出錯找誰？                                                                                         | 腳本不進本系統的 repo，要有負責的人                                              | U-4        |
| 5   | 3 分鐘一次、整天附加，檔案會一直變大；可以只在透析時段抓，或內容沒變就不附加嗎？頻率多少算「過高」？                                       | 兩種做法都會改到「跟原本一樣」，要學長同意                                       | U-8        |
| 6   | `hb` 那支 API 的 `.json` 範例方便傳嗎？是另一支端點嗎？要不要週一一起排程？                                                                | 決定腳本要抓一支還是兩支                                                         | U-9        |
| 7   | 腳本呼叫院方 API、存成檔，本系統與 APP 組讀檔：要不要另外知會資訊室？存檔位置與留存期限要不要院方核可？院方 API 改版或停機，會有人通知嗎？ | 醫師已授權學長決定，這一題由學長定（清冊 Q-35）                                  | U-10       |
| 8   | 第二次進院時，本系統要用唯讀方式讀那個資料夾，可以嗎？                                                                                     | 讀檔模式的前提，先講好                                                           | 第 7 節    |
