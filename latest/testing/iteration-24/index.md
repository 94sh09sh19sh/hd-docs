# 迭代 24 手動測試 — 遊戲化之五：花園與相簿的擴充

> 《[完整手動測試手冊](https://94sh09sh19sh.github.io/hd-docs/latest/testing/manual-test-guide/index.md)》的分冊之一，對應《實作規格書》4.24 節。 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 24 的部分。 操作端色籤（**護理端**／**病人端**／**終端機**／**資料庫**）的意思見主手冊 §00。 項次用 `ah`（實作規格書 4.0.5：24 用 `ah`），從 `ah1` 起。

**這一冊驗六件事**： 兩個開關關著時一切跟迭代 23 一樣； 種子袋每次療程補到 3 顆、袋子不會越積越多、畫面上沒有「上限」； 小訪客一半的機會來、沒點不離開、一次最多一隻、點了不給任何東西； 花園圖鑑照分類排、空格不洩漏名字； 相簿圖鑑「我的相簿」收翻開過的每一張（「想起某個人」照收）、只跳過的與下架的不在、沒有對錯； 新的 48 張花、24 張訪客、60 張圖卡逐張看過、請長者試看。 決定與設計在子文件《[透析中的遊戲化之四：花園與相簿的擴充](https://94sh09sh19sh.github.io/hd-docs/latest/notes/dialysis-gamification-expansion/index.md)》；花的清單在《[之二](https://94sh09sh19sh.github.io/hd-docs/latest/notes/dialysis-gamification-garden/index.md)》、圖卡在《[之三](https://94sh09sh19sh.github.io/hd-docs/latest/notes/dialysis-gamification-album/index.md)》。

## §24.1 開關關著照舊

- `ah1` **［病人端］** 📐 「透析小花園」「老台灣記憶相簿」都關著：看首頁、遊戲選單。 → 跟迭代 23 一樣：兩款都不在遊戲選單（其他遊戲都關著時首頁沒有遊戲圖示）。**［終端機］** 打 `GET /api/device/games/album/collection` 回 404。
- `ah2` **［資料庫］** 看 `game_saves`，找這一位病人。 → 開關關著時**沒有**這位病人的花園存檔（什麼都不寫）。

## §24.2 種子袋

- `ah3` **［護理端］** 開「透析小花園」。**［病人端］** 📐 遊戲選單點「透析小花園」。 → 12 格空地；門口（右邊）一句「點一格空地，種下第一顆種子」與「這次有 3 顆種子」。**［資料庫］** `game_saves` 已經有一列、`format_version` 是 2（第一次點開就寫下空花園）。
- `ah4` **［病人端］** 種三棵（三種種子各一顆也可以）。 → 每種一棵，那一句變「這次還有 2 顆種子」「這次還有 1 顆種子」，第三棵之後是「**這次的種子種完了，下次來會再有 3 顆**」。
- `ah5` **［病人端］** 再點一格空地。 → **點不開**（空地只是一塊地，按下去沒有反應、沒有變暗）；畫面上\*\*沒有「上限」「不能種」「已達」\*\*這種字，也沒有灰掉的按鈕。
- `ah6` **［終端機］** 照平板的格式直接送第 4 顆（`POST /api/device/games/garden/events`，`PLANT`、序號接著上一步）。**［資料庫］** 看 `game_events` 最後一列。 → 回應的 `ignored` 是 1、那一格還是空地；`game_events` 多一列 `PLANT`、`applied` = 0，序號照樣用掉。
- `ah7` **［病人端］** 📅 同一位病人**跳過三次療程不點開花園**（排三次以前的療程），再點開。 → 那一句是「這次有 3 顆種子」——**不是 9 顆**（補到 3 顆，不是累加）。
- `ah8` **［病人端］** 📅 分幾次療程把 12 格種滿。 → 門口只有「花園滿了，可以把開好的花送出去或種到大家的花園，再種新的」那一句（袋子裡有沒有種子都一樣），**沒有紅點、數字或提醒**。
- `ah9` **［病人端］** 拔掉網路，在新的一次療程種三棵；接回網路。 → 斷線時照樣種得下三棵、第四格點不開；接上之後**伺服器算的跟平板一樣**（重新點開花園，三棵都在、開的是同一種花）。

## §24.3 小訪客

- `ah10` **［病人端］** 📅 每次療程點開花園一次，看門口那一欄最下面那一格。 → 大約一半的療程有一隻（鳥、蝴蝶或小動物）停在那一格；**最多連續兩次療程空著**，第三次一定來。沒有訪客時那一格空著，**不寫「還沒來」**。訪客**不蓋住任何一格植物**，是靜態圖，不飛、不閃。
- `ah11` **［病人端］** 📅 有一隻在等的時候，**接著兩三次療程點開花園都不點牠**。 → 還是**同一隻**在等，沒有離開、沒有換、沒有第二隻。
- `ah12` **［病人端］** 記下每一棵現在的樣子與門口的澆水、養分，然後點那一隻。 → 換成一頁：左邊大圖、右邊名字與一句說明（例如「麻雀：曬穀場上最常見，一群一群來啄穀子」），左下角回我的花園。回到花園：那一格空了；**每一棵的樣子、澆水、養分、種子那一句都沒變**（點了不給任何東西），畫面上沒有「＋1」「謝謝」之類的回饋。
- `ah13` **［病人端］** 同一次療程再點開花園。 → 這一次療程**不會再來第二隻**（一次療程只判斷一次）。
- `ah14` **［資料庫］** 看 `game_events` 與 `garden_visitors`。 → 每次點開花園的療程有一列 `LOOK`（來了的那一列 `visitor_code` 是那一隻，沒來的是空的）；點開那一隻是一列 `VISITOR`；`garden_visitors` 有這一位病人、這一種、第一次點開的時間。
- `ah15` **［病人端］** 📅 拔掉網路，在新的一次療程點開花園；有訪客來的話點開牠；接回網路。 → 斷線時照樣會來、點得開；接上之後重新點開花園，伺服器算出的是**同一隻**（或同樣沒來），圖鑑裡也收進去了。

## §24.4 花園圖鑑

- `ah16` **［病人端］** 📐 花園頂列點圖鑑圖示。 → 先是一頁目錄：「圖鑑」標題、四顆大按鈕「樹上開的花／田裡開的花／庭院與水邊的花／花園的訪客」，每顆有一張小圖與「收到 N 種，共 12 種」（訪客是「共 24 種」）。頂列右邊是「以前的花園」；左下角回我的花園。
- `ah17` **［病人端］** 點「樹上開的花」。 → 一頁 4×3 共 12 格，**照固定順序**：第一格是梅花、第二格油桐花、第三格杜鵑花……開過的是花與名字，**沒開過的是淡色、細線框的空格——沒有名字、沒有問號、沒有剪影**；標題底下「收到 N 種，共 12 種」。
- `ah18` **［病人端］** 點一格開過的花。 → 大圖、名字、一句說明；左下角回上一頁。點空格沒有反應。
- `ah19` **［病人端］** 回圖鑑，點「花園的訪客」。 → 一群一頁 4×2：「花園的訪客：鳥」→ 下一頁「會飛的蟲」→「草叢與水邊」（頂列三個圓點）；排法同 `ah17`，點開看過的那一隻是大圖、名字與說明。
- `ah20` **［病人端］** 開讀螢幕（Android 的 TalkBack 或電腦的螢幕閱讀程式）摸過一頁圖鑑。 → 收到的唸得出名字；**空格什麼都不唸**（沒有替代文字）。
- `ah21` **［病人端］** 另一位病人點開圖鑑。 → 只看得到自己收到的，**沒有排名、沒有跟別人比**。
- `ah22` **［病人端］** 圖鑑頂列點「以前的花園」。 → 跟迭代 21 一樣（一頁四個月份，點進去是那一座、只能看）。

## §24.5 我的相簿

- `ah23` **［護理端］** 開「老台灣記憶相簿」。**［病人端］** 📐 點進相簿。 → 封面下緣兩顆大按鈕並排：「翻開相簿」「我的相簿」；「已經翻過 N 張」照樣在。
- `ah24` **［病人端］** 翻開一次：第 1 張點「想起某個人」、第 2 張「跳過這張」、第 3 張「這是什麼？」**故意選錯**、點「我用過」「我家也有」，其餘照常看完。回封面點「我的相簿」。 → 目錄一頁 4 個主題（三頁），每顆寫主題名稱與「翻過 N 張，共 10 張」，有收到的主題用收到的第一張當小圖。
- `ah25` **［病人端］** 點「灶腳與餐桌」（或剛剛那幾張所在的主題）。 → 一頁 5×2，照圖卡的固定順序排（電鍋、大灶……）；翻開過的四張（含選錯的那一張、點了「想起某個人」的那一張）是圖與名稱，**點「想起某個人」的那一張看不出任何差別**；**只跳過的那一張是空格**；沒翻過的是空格、沒有名字。
- `ah26` **［病人端］** 點開「想起某個人」的那一張與選錯的那一張。 → 大圖、名稱、一句說明，底下列出那一次點的貼紙（「想起某個人」與其他貼紙同一個樣子、點不了）；**沒有寫選了什麼、沒有「答對」「答錯」、沒有列選項**。
- `ah27` **［護理端］** 系統管理 → 內容與選項 → 記憶相簿的圖卡：把剛剛收到的一張「下架」（填理由）。**［病人端］** 重新點開我的相簿。 → 那一張不見了，那一個主題變「共 9 張」（下架的不算進總數）。做完重新上架。
- `ah28` **［護理端］** 改一張收到的圖卡的說明（填理由）。**［病人端］** 點開那一張。 → 看到的是**改過的**說明（一律顯示目前那一版）。
- `ah29` **［病人端］** 拔掉網路，點「我的相簿」。 → 一句「連上網路之後再翻」；接回網路再點就看得到。
- `ah30` **［護理端］** 看病人詳細資訊「可以聊的話題」。 → 跟迭代 23 一樣；**我的相簿不在護理端出現**。

## §24.6 新內容逐張檢查與長者試看

- 🛠 照《之二》第 7 節、《之四》第 4.2 節逐張看新的 24 種花（花苞與開花各一張）與 24 種訪客：沒有人、手、文字；沒有紅色（燕子的喉部是深棕）；長得像的分得出來（蜻蜓與豆娘、獨角仙與鍬形蟲）。新的 60 張圖卡在 23.x 的那一次逐張檢查已經記在《之三》第 6 節，這一冊不重做。
- 🛏 請社工看新的主題、訪客（含貓狗要不要收）、粉紅康乃馨，護理部看一句說明，長者在病床上實際看一次：認不認得、像不像給小孩玩的。**這一項不打勾，結果寫回《之四》第 9 節**（與迭代 21、23 的一起看，清冊 Q-31 第 9 題）。

## §24.7 版面與自動化驗收

- `ah31` **［病人端］** 📐 1280×800：花園（水與四份養分都在、種子那一句、訪客在等）、點開的訪客、圖鑑目錄、一類一頁、相簿封面、我的相簿的目錄、一個主題、點開一張，每一頁都看一次。 → **都不捲動**；求助區在原位；可點的都至少 64px，花園的一格與訪客那一格至少 96px；沒有動畫、沒有聲音、沒有紅色（求助區以外）。
- `ah32` **［病人端］** 遊戲畫面放著三分鐘不動。任務時點到了的時候正在圖鑑裡。 → 跟迭代 21 一樣：三分鐘回首頁；任務全螢幕出現，做完問一次「回到剛剛的遊戲？」。
- `ah33` **［終端機］** `npm run verify:iteration24`（不需要後端）；後端開著，再跑 `npm run verify:iteration24:api`。 → 兩支都全部通過（前一支實際跑種子袋、四百座花園各三十次療程的訪客、第 1 版快照升級、兩個圖鑑的排法與空格、字型，再跑迭代 20～24.3 的驗收與 `check:egress`、`check:ui`、`check:ui:design`；後一支結束時兩個開關改回原狀、下架的那一張改回、療程取消）。
- `ah34` **［終端機］** `npm run verify:iteration24-1`、`npm run verify:iteration24-2`、`npm run verify:iteration24-3`。 → 照樣通過（36 種花、24 種訪客、120 張圖卡的內容與圖沒有因為 24.4 而變）。
