## §27.2.1 進度條的字與刻度

- `ak37` **［病人端］** 🛠 📐 1280×800 看最上面那一框的進度條。 → 進度條**左邊沒有時鐘圖示**；進度條底下一行小字，左邊「剩 X 小時 Y 分」（整點時「剩 X 小時」、不到一小時「剩 Y 分」），右邊「HH:MM 結束」，**右端對齊進度條的右端**。沒有開始時間、經過幾分鐘、百分比。
- `ak38` **［病人端］** 拿最右邊的現在時間與「HH:MM 結束」心算相減。 → 與「剩 X 小時 Y 分」**完全相同**，不會差 1 分（例如 11:06、13:25 結束，寫「剩 2 小時 19 分」）。結束時間＝開始後四小時，與面板橫軸右端的時間相同。
- `ak39` **［病人端］** 看進度條上的刻度。 → **三條**，把進度條分成四等分（每格一小時）；填色的部分與還沒填的部分上都看得到，刻度上沒有字。
- `ak40` **［病人端］** 開著不要碰，等到現在時間換到下一分鐘。 → 現在時間換的同時，「剩幾分」少 1 分，**兩個一起換**，不會一個換了一個還沒換。
- `ak41` **［病人端］** 開發者工具的無障礙樹看那條進度條（或用螢幕閱讀器）。 → 念出「療程時間」與「剩 X 小時 Y 分，HH:MM 結束」，不是只有百分比。

## §27.2.2 擠的時候與過了結束時刻

- `ak42` **［病人端］** 🛠 📐 照 27.1 分冊 `ak19` 做出最壞組合（床號 A12、姓名 4 個字、1 個任務圖示、遊戲圖示、「護理師收到了」）。 → **仍是一列**；剩餘時間**整句看得到、沒有被截**；「HH:MM 結束」不見（放不下就先收它）。護理端結案之後（狀態變「已處理」）仍收著；求助那一句不見了（換下一次透析，或等到沒有任何狀態）就回來。開發機實量：最壞組合進度條區塊 159px、剩餘那一句 131px（實作規格書 4.27.2 驗收現況）。
- `ak43` **［病人端］** 讓病人過了開始後四小時還沒下機（`demo:patient` 的模擬戊是透析到一半，開著等大約兩小時；剩餘分鐘怎麼算由 `verify:iteration27-2` 第 2 步直接餵時間驗，這一項只看畫面）。 → 進度條**滿格**；「剩幾分」那一句**不見**，只留「HH:MM 結束」靠右；**沒有**「超過幾分」「已超時」之類的字，沒有變色或閃。

## §27.2.3 血壓單位

- `ak44` **［病人端］** 🛠 📐 看「本次透析」面板的血壓圖。 → 標題「血壓」右邊、小一級寫「**毫米汞柱**」，與脫水量的「公斤」同一種寫法；線尾的兩個數字照舊不帶單位；畫面上沒有 mmHg。

## §27.2.4 自動化驗收

`npm run verify:iteration27-2`（不需要後端，要先 `npm run build:shared`）：剩餘時間的寫法、剩餘分鐘是時分相減、首頁沒有時鐘圖示與三條刻度、樣式（欄距 24px、最窄是剩餘那一句、容器查詢）、血壓單位、`clock` 已從圖示登記拿掉、新字都在自帶字型裡，並連帶跑病人端既有的八支驗收。`verify:iteration27-1` 的「最窄 100px」隨需求改成「有最窄的寬」（實作規格書之一第二十三次）。這一節不另列項次，跑的結果記在 `ak37` 那一輪的驗收紀錄。
