# 迭代 20 手動測試 — 遊戲化之一：平板現有功能的遊戲化

> 《[完整手動測試手冊](https://94sh09sh19sh.github.io/hd-docs/latest/testing/manual-test-guide/index.md)》的分冊之一，對應《實作規格書》4.20 節。 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 20 的部分。 操作端色籤（**護理端**／**病人端**／**終端機**／**資料庫**）的意思見主手冊 §00。 項次用 `ad`（實作規格書 4.0.5：20 用 `ad`），從 `ad1` 起。

**這一冊驗五件事**： 三個開關全關時病人端與護理端都跟迭代 17.7 一樣； 任務做完的完成記號與那一句（與答案無關）；衛教測驗的結果不給病人看錯題、我的衛教小本子； 病友小撇步（只能選、不能打字，署名只到「本中心病友」）與跑馬燈的「你知道嗎」； 被聽見的回覆（下一次透析出現一次，護理端沒有未讀數與待辦）。 **獎勵的是「做了」**：每一項都可以換一種答法再做一次，看到的應該一模一樣。

**前置**：一台已佈建的平板（或瀏覽器開病人端）、一位合成病人；一般護理師與護理長帳號。 心情問卷與衛教要等透析開始後兩、三小時才出現：測試時到系統管理 → 營運參數，把「心情問卷出現時點」「衛教出現時點」暫時改成 0（做完改回）。 三個開關在系統管理 → 功能開關的「病人平板的遊戲化」那一組。

## §20.1 三個開關全關

- `ad1` **［護理端］** 系統管理 → 功能開關。 → 多一組「病人平板的遊戲化」：現有功能的小幅遊戲化（開）、病友小撇步（關）、護理師回貼圖（關）。畫面上沒有任何英文識別字。麻將、相簿**還沒有開關**（功能還沒做）。**1010 迭代 21 起**這一組多透析小花園、送花、病人之間的互動三列（共六列，見迭代 21 分冊 `ae1`），**1011 迭代 22 起**再多麻將連連看、狀態評估彙整兩列（共八列，見迭代 22 分冊 `af1`）；迭代 20 剛做好時只有這三列。
- `ad2` **［護理端］** 把「現有功能的小幅遊戲化」關掉（寫理由），三個都關著。**［病人端］** 📐 做一次透析前問卷、心情問卷、衛教與測驗。 → 每一個畫面都跟迭代 17.7 一樣：問卷送出直接回首頁，基本資訊區一下「已送出」／「謝謝您」；測驗結果是「3／5」與一排勾叉、答錯的各一頁說明；做完回首頁。**沒有「完成了」、沒有小本子、沒有「我也是這樣做的」**。
- `ad3` **［護理端］** 📐 專業版病人趨勢、公告與院內衛教，簡易版的「＋」，系統管理 → 內容與選項。 → 回饋表沒有「回一張」欄；公告與院內衛教沒有「要一則『你知道嗎』」；簡易版「＋」只有院內衛教與公告兩種；內容與選項沒有「病友小撇步」分頁。
- `ad4` **［終端機］** 三個都關著時，拿平板的權杖打 `GET /api/device/education/notebook`、`GET /api/device/peer-tips`，拿護理師的權杖打 `GET /api/patients/<病人>/nurse-replies`、`GET /api/content/peer-tip-presets`。 → 都回 404「此功能未啟用」——後端一併擋下，不是只靠畫面藏。做完把「現有功能的小幅遊戲化」開回來。

## §20.2 送出後的那一句與完成記號

- `ad5` **［病人端］** 📐 透析前問卷全部答「沒有」，送出。 → 不回首頁，出現一頁：中間一個完成色外框，裡面一個勾與「完成了」，底下「謝謝，護理師會照這個照顧你」。**沒有灑花、沒有彈跳、沒有聲音、什麼都不會動**；求助按鈕照常在下面、位置不變。按右下的勾或右上的房子回首頁。
- `ad6` **［病人端］** 下一次問卷到期時，這次每一題都答「有」、程度選最重，送出。 → 看到的跟 `ad5` **一字不差**（那一句與答案無關）。
- `ad7` **［病人端］** 拔掉網路，填一次透析前問卷送出。 → 完成記號照樣出現，底下那一句是「已存在平板，有網路時會自動送出」（不是感謝的話）；接回網路後自動送出。
- `ad8` **［病人端］** 心情問卷答完送出；換一次全部選最差的再做一次（換一位病人或下一次透析）。 → 兩次都是「完成了」＋「謝謝你告訴我們，護理師都會看」，一樣。
- `ad9` **［病人端］** 在完成那一頁什麼都不碰，等過閒置門檻（預設 60 秒）。 → 自動回首頁。每一句都沒有「好棒棒」「太厲害了」、沒有驚嘆號。

## §20.3 一起看答案與我的衛教小本子

- `ad10` **［病人端］** 📐 做衛教測驗，故意答錯兩題，送出。 → 不出現「3／5」、沒有叉叉；每一題一頁「一起看答案」：題目、一個勾與正確答案、說明。**答對、答錯的題目看起來一樣**，看不出哪幾題錯；病人選的答案不出現。最後一頁按勾。
- `ad11` **［病人端］** 接著出現衛教做完的那一頁。 → 「完成了」＋「今天的衛教看完了，謝謝你」，下面一顆「翻我的小本子」（書與愛心的圖示）。**首頁沒有這顆**。
- `ad12` **［病人端］** 按「翻我的小本子」。 → 第一次可能是「衛教小測驗答對的主題，會收在這裡」；同一個主題連續答對兩題之後，那個主題亮起：一頁一個主題，主題名稱與一句重點（題目的說明）。**沒有錯題、錯題數、分數**；頁數用頂端的圓點，下一頁用右下的箭頭，沒有捲軸。
- `ad13` **［病人端］** 下一次測驗故意把已經亮起的那個主題答錯，再翻小本子。 → 那個主題**照樣亮著**（亮了不熄）。
- `ad14` **［護理端］** 專業版結束與離院衛教／病人趨勢看同一位病人。 → 護理端照舊看得到答錯的知識點（迭代 17.7 的樣子），小本子不影響護理端。

## §20.4 病友小撇步

- `ad15` **［護理端］** 開「病友小撇步」。系統管理 → 內容與選項。 → 多一個「病友小撇步」分頁，12 則預設，每則有衛教主題、選過幾次、使用中；有「改文字」「停用」，**沒有刪除**。新增一則時識別碼要大寫英文、超過 53 字按不下去、要填理由。
- `ad16` **［病人端］** 📐 做完衛教，在做完的那一頁按「我也是這樣做的」。 → 「我也是這樣做的」與一句「選一則分享給其他病友，名字不會出現，只寫『本中心病友』」；下面最多四則小撇步，跟剛看完的主題有關的在前面。**整個畫面沒有任何可以打字的地方**。
- `ad17` **［病人端］** 點一則。 → 那一則變成選中的樣子，上面寫「謝謝你分享，護理師看過之後會放給其他病友看」；再點同一則沒有反應。**病人端跑馬燈還沒有它**。
- `ad18` **［護理端］** 公告與院內衛教（專業版）／簡易版的草稿卡。 → 待核准多一則「病友小撇步：\<原文>（本中心病友）」，從哪裡來寫「病友選的小撇步（病友選過 1 次）」，簡易版草稿卡上是兩個人的圖示。**沒有病人姓名、病歷號、床號**。另一位病人選同一則之後，**不會多一份**，只變成「選過 2 次」。
- `ad19` **［護理端］** 核准它。**［病人端］** 看跑馬燈。 → 跑「病友小撇步：…（本中心病友）」，沒有床號與姓名。
- `ad20` **［護理端］** 讓另一則停在待核准，然後關掉「病友小撇步」。 → 已核准的那一則**照樣在跑馬燈播**；待核准的那一則從清單消失、核准不了；病人端衛教做完的那一頁沒有「我也是這樣做的」；內容與選項的分頁不見。開回來時，待核准的那一則回來。

## §20.5 跑馬燈的「你知道嗎」

- `ad21` **［護理端］** AI 開著時，公告與院內衛教 → 「要一則『你知道嗎』」（簡易版是「＋」裡的卷軸圖示）。 → 一會兒後待核准多一則「你知道嗎：…」（模擬供應者時是固定範例）。送進 AI 的只有這個月是幾月：到系統管理的 AI 呼叫紀錄看那一筆的提示，**沒有任何病人資料**。
- `ad22` **［護理端］** 核准。**［病人端］** 看跑馬燈。 → 照樣是「標題：內容」整則跑完；長度超過上限的核准不了（跟衛教一樣）。
- `ad23` **［護理端］** 關掉「現有功能的小幅遊戲化」。 → 病人端跑馬燈**不再播**那一則；「要一則『你知道嗎』」不見，簡易版「＋」只剩兩種；開回來又接著播。

## §20.6 被聽見的回覆

- `ad24` **［護理端］** 開「護理師回貼圖」。**［病人端］** 心情問卷最後一頁寫「冷氣有點冷」送出。
- `ad25` **［護理端］** 📐 專業版病人趨勢 → 選這位病人 → 這位病人的回饋。 → 表格多一欄「回一張（可以不回）」：寫了字的那一列有四個貼圖（愛心、讚、太陽、手捧愛心）與三句預設回覆；沒寫字的那一列空著。點一個貼圖 → 那一格變成貼圖與那一句、誰回的、「病人下一次透析時會看到」，**按鈕不見了**（一則只回一次）。**沒有可以打字的地方**。
- `ad26` **［護理端］** 走一遍即時總覽、主列、簡易版、常駐總覽螢幕。 → **哪裡都沒有**回覆的紅點、數字、待辦或提醒；不回也沒有任何東西追著護理師。
- `ad27` **［病人端］** 同一次透析裡回首頁、重新整理。 → **這次透析看不到**那張貼圖。解除綁定，下一次透析（同一位病人、換一台平板也可以）接上平板。 → 到期的問卷先出現；回首頁之後出現一頁「護理師回你」，一個大大的太陽（或你點的那一個）與那一句。**沒有護理師的名字、沒有引用病人上次寫的字**。按勾回首頁。
- `ad28` **［病人端］** 再回首頁、重新整理。**［護理端］** 看那一格。 → 病人端**不再出現**；護理端那一格寫「病人 MM/DD HH:mm 看到了」——只是事實，不是提醒。

## §20.7 長者試看

- `ad29` **［病人端］** 🛏 請一位長者在病床上看一次：完成那一頁、一起看答案、小本子、我也是這樣做的、護理師回你。 → 問三題：看得清楚嗎、知道下一步按哪裡嗎、會不會覺得被打分數。記下回答與平板的型號、亮度；回答寫進遊戲化分析 12.2 的試辦紀錄。

## §20.8 自動化驗收

- `ad30` **［終端機］** `npm run verify:iteration20`（不需要後端）；後端開著，再跑 `npm run verify:iteration20:api`。 → 兩支都全部通過（前一支會再跑 `check:ui`、`check:ui:design`、`check:egress`；後一支結束時五個開關與夜間時段改回原狀、這次核准的跑馬燈內容下架、新增的預設小撇步停用。驗收用的平板、病人留著，與其他驗收腳本相同）。
