## 17.6.1 · 簡易版：草稿換則、「＋」的位置 🎬 📐

- `aa114` **［護理端］** 開 `http://localhost:5183`，1366×768 簡易版。公告與院內衛教那一框，點左欄圖示底下的「＋」要一份公告，連要三份（事由隨便寫）。 → 「＋」在框左欄、喇叭圖示底下（與病人框的重新整理同一處），**不在清單裡佔一格**。等幾秒草稿寫好。
- `aa115` **［護理端］** 看草稿卡底下。 → 有一列「‹ 1／N ›」（N 是待核准加上寫到一半的份數）。只有一則時這一列不出現。
- `aa116` **［護理端］** 按 › 兩次。 → 草稿卡換成第二則、第三則，字整則看得完；換到最後一則時 › 按不下去，‹ 按得下去。整頁仍沒有捲軸。
- `aa117` **［護理端］** 停在第三則，按卡旁的核准（勾）。 → 核准的是**第三則**（下面已核准的清單多出它的標題）；草稿卡換成原本的第四則，「‹ 3／N−1 ›」。按復原列的復原，那一則回到待核准。
- `aa118` **［護理端］** 換到某一則，把草稿卡拖到一台有床號的平板（或點草稿卡、再點平板）。 → 核准的是卡上那一則，只在那一床播。看一眼下面的已核准清單：第一格整格看得到，沒有被切掉一半。

## 17.6.2 · 專業版：新增裝置與系統管理的平板停用 🎬

- `aa119` **［護理端］** 切到專業版，看上面那一排。 → 六項：即時總覽、緊急通報、排班與指派、**新增裝置**、公告與院內衛教、總覽螢幕模式。沒有「裝置管理」，也沒有「病人」。
- `aa120` **［護理端］** 點「新增裝置」。 → 只有兩塊：「註冊新平板」（序號、標籤、註冊）與「平板清單」。**沒有「目前有效綁定」**；平板清單沒有「裝置操作」那一欄、沒有任何按鈕，狀態欄（綁定狀態、可否指派、固定狀態、外殼版本、裝置佈建、最後連線）都在。
- `aa121` **［護理端］** 註冊一台 `TB-176`（標籤自訂）。 → 出現佈建 QR code 與網址；清單多一列 `TB-176`，裝置佈建是「已佈建」。
- `aa122` **［護理端］** 右上角「系統管理」→「平板停用」。 → 每一台沒在用的平板有「停用」與「解除佈建」兩顆；正在服務病人的那一台寫「先下機才能停用」，旁邊仍有「解除佈建」。
- `aa123` **［護理端］** 對 `TB-176` 按「解除佈建」→「確定解除佈建」。 → 綠色提示「平板 TB-176 已解除佈建」；那一列狀態變「未佈建」、只剩一顆「登記佈建」，排到表的最後。回「新增裝置」看，它的裝置佈建是「未佈建」、可否指派寫原因。
- `aa124` **［護理端］** 回系統管理「平板停用」，對 `TB-176` 按「登記佈建」。 → 狀態回到「可使用」，又有「停用」與「解除佈建」。

## 17.6.3 · 專業版：沒有病人頁；排班與指派的病人順序與重新整理 🎬

- `aa125` **［護理端］** 網址列直接開 `http://localhost:5183/patients`。 → 沒有病人頁（路由不存在，回到即時總覽）。「更多」選單裡也沒有「病人」。
- `aa126` **［護理端］** 簡易版看病人框的順序，記下來；切到專業版「排班與指派」，點開「選擇病人…」那個下拉選單。 → 正在透析的在最上面、**越晚開始越上面**；其餘依姓名筆畫。與簡易版病人框同序（下拉選單多了已經配好平板的病人，例如模擬戊，夾在他的開始時間該在的位置）。
- `aa127` **［護理端］** 下拉選單旁有一顆「⟳ 重新整理」，按一下。 → 按鈕先變灰、一兩秒後恢復；沒有錯誤提示。模擬院方資料每 3 分鐘才抓一次，剛上機的病人按了之後馬上排到最上面。
- `aa128` **［護理端］** 看當日排班清單上方的說明與清單下方的提示（有跨日綁定或沒有可指派平板時才出現）。 → 不再叫人去「裝置管理」的「目前有效綁定」；提到的是「新增裝置」與系統管理的「平板停用」。
