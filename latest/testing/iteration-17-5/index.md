## 17.5.1 · 沒有預計結束時間的病人：三處一致 🎬 📐

`npm run demo:patient` 開著。它配給 DEMO-01 的「模擬戊」（B1）**刻意沒有預計結束時間**。

- `aa105` **［病人端］** 用 `demo:patient` 印出來的網址開 DEMO-01，1280×800。看面板血壓圖下方的兩個時間。 → 左邊是透析開始（例如 `09:20`），右邊**正好晚四小時**（`13:20`）。
- `aa106` **［病人端］** 同一個畫面看最上面那一框的療程進度條。 → 填滿的比例 ≈（現在 − 開始）÷ 4 小時。例如 09:20 開始、11:06 看，約 44%。**不是**接近 0%，也不是按 6 小時算的三成左右。
- `aa107` **［護理端］** 護理端開 `http://localhost:5183`，1366×768 簡易版，看 DEMO-01（右上角 B1）那一格病人名牌下的進度條。 → 與病人端進度條差不多長（同一分鐘看，相差不超過 1%）。**剛配上的病人透析了一陣子，進度條不會從 0 開始**（17.4 以前會）。
- `aa108` **［護理端］** 簡易版把病人框裡另一位正在透析、沒有平板的病人（名牌右上角有折線圖示的）拖到一台空平板上配好，再看那一格。 → 進度條一出現就是「從他的透析開始時間算起」的長度，不是 0%。做完用專業版「手動解除」復原（或重開 `demo:patient`）。

## 17.5.2 · 有預計結束時間的病人：照舊 🎬

- `aa109` **［護理端］［病人端］** 用 `aa108` 的做法把「模擬己」配上一台平板（他有預計結束時間），護理端那一格與他的病人端各看一次進度條。 → 兩邊差不多長，病人端面板橫軸右邊的時間就是他的預計結束時間。 模擬院方資料的預計結束一律剛好是開始後四小時，所以畫面上**分不出**「用了預計結束」還是「用了四小時」——「有預計結束就用它」由 `aa110` 的步驟 1 實際跑一次來驗。

## 17.5.3 · 自動化驗收 🖥

- `aa110` **［終端機］** `npm run verify:iteration17-5`（不需後端、不需資料庫）。 → 5 個步驟全部 ✓。步驟 5 會順便跑 `verify:iteration14`、`15`、`16`、`17-2`、`17-4`，也都要通過。
