# 迭代 17.5 手動測試 — 透析一律開始後四小時結束

> 《[完整手動測試手冊](https://94sh09sh19sh.github.io/hd-docs/latest/testing/manual-test-guide/index.md)》的分冊之一，對應《實作規格書》4.15.5 節與《[迭代 17.5 修正紀錄](https://94sh09sh19sh.github.io/hd-docs/latest/notes/iteration-17-5-fixes/index.md)》。 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 17.5 的部分。 操作端色籤（**護理端**／**病人端**／**終端機**／**資料庫**）的意思見主手冊 §00。 項次接著迭代 17.4 分冊編（`aa105` 起；17.4 用到 `aa104`），小版沿用那個迭代的字母。

**這一冊驗一件事**：一次透析一律在**開始後四小時**結束（本透析中心的院方硬性規定），**不管院方資料有沒有預計結束時間**。 病人端進度條與面板橫軸、護理端簡易版平板格、專業版即時總覽、總覽螢幕模式的進度都照這一條，彼此一致；「待確認下機」也以開始後四小時判定。

## 17.5.1 · 病人端與簡易版：開始後四小時 🎬 📐

`npm run demo:patient` 開著。它配給 DEMO-01 的「模擬戊」（B1）**刻意沒有預計結束時間**。

- `aa105` **［病人端］** 用 `demo:patient` 印出來的網址開 DEMO-01，1280×800。看面板血壓圖下方的兩個時間。 → 左邊是透析開始（例如 `09:20`），右邊**正好晚四小時**（`13:20`）。
- `aa106` **［病人端］** 同一個畫面看最上面那一框的療程進度條。 → 填滿的比例 ≈（現在 − 開始）÷ 4 小時。例如 09:20 開始、11:06 看，約 44%。**不是**接近 0%，也不是按 6 小時算的三成左右。
- `aa107` **［護理端］** 護理端開 `http://localhost:5183`，1366×768 簡易版，看 DEMO-01（右上角 B1）那一格病人名牌下的進度條。 → 與病人端進度條差不多長（同一分鐘看，相差不超過 1%）。**剛配上的病人透析了一陣子，進度條不會從 0 開始**（17.4 以前會）。
- `aa108` **［護理端］** 簡易版把病人框裡另一位正在透析、沒有平板的病人（名牌右上角有折線圖示的）拖到一台空平板上配好，再看那一格。 → 進度條一出現就是「從他的透析開始時間算起」的長度，不是 0%。先不要解除，下一節要用。

## 17.5.2 · 專業版即時總覽與總覽螢幕模式 🎬

- `aa109` **［護理端］** 切到專業版 → 即時總覽，看「模擬戊」與 `aa108` 那一位的「療程進度」。 → 進度條長度與簡易版那一格相同；文字「X小時Y分」是**從透析開始**算起經過的時間（例如 09:20 開始、11:06 看是 1小時46分），不是從平板配上的時間算起。
- `aa110` **［護理端］** 開 `http://localhost:5183/wall`（總覽螢幕模式），看同兩位的磚塊。 → 進度條與「已進行 X 小時 Y 分」與即時總覽相同。做完用專業版「手動解除」把 `aa108` 那一位復原（或重開 `demo:patient`）。

## 17.5.3 · 有預計結束時間的病人也是四小時 🎬

- `aa111` **［護理端］［病人端］** 用 `aa108` 的做法把「模擬己」配上一台平板（他有預計結束時間），護理端簡易版、即時總覽與他的病人端各看一次。 → 三處一樣長，病人端面板橫軸右邊是**開始後四小時**。 模擬院方資料的預計結束一律剛好是開始後四小時，所以畫面上**分不出**有沒有用到院方的預計結束——「院方的預計結束不影響」由 `aa113` 的步驟 1、5 與 `aa112` 驗。

## 17.5.4 · 自動化驗收 🖥

- `aa112` **［終端機］** 照主手冊開模擬院方 API（`npm run dev:hospital-sim`），後端帶 `HOSPITAL_API_BASE_URL=http://localhost:8090/dialysislist.php` 啟動，再跑 `npm run verify:iteration15:api`。 → 12 個步驟全部 ✓；「待確認下機」那兩條：院方的預計結束已過 70 分鐘、開始才 30 分鐘的**不標**；開始 310 分鐘前、沒有預計結束的**要標**。
- `aa113` **［終端機］** `npm run verify:iteration17-5`（不需後端、不需資料庫）。 → 6 個步驟全部 ✓。步驟 6 會順便跑 `verify:iteration14`、`15`、`16`、`17-2`、`17-4`，也都要通過。
