    迭代 14 手動測試 — 介面極簡重設計¶

    《完整手動測試手冊》的分冊之一，對應《實作規格書》4.12 節。 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 14 的部分。 操作端色籤（護理端／病人端／終端機／資料庫）的意思見主手冊 §00。

    這一冊驗的是極簡四條有沒有落到畫面上：能用圖示就不用文字、用框線與顏色分區、不影響功能的字全刪、能不捲動就不捲動。 病人端全部重做（首頁三區、任務依時點全螢幕出現），護理端新做簡易版並設為每次登入的預設；專業版不動。 規則的真本是《介面設計基準》第 0.1、2.4、3.5、4.6～4.10 節。

    標記 意思
    🖥 開發機 平常的開發環境，npm run dev
    📱 目標尺寸 在基準 4.10 的尺寸下看：1280×800、800×1280（病人端）與 1366×768、1920×1080（護理站）。0930 平板確定 10 吋，病人端這兩個尺寸就是 10 吋平板的 CSS 尺寸；型號未定

    • x2 ［終端機］ 開 .claude/skills/hd-uiux/SKILL.md。 → 第 0 節寫著極簡四條與「專業版不動」；有 2.4、3.4、4.6～4.9；與基準文件沒有互相矛盾的數字。
    • x3 ［終端機］ 開 scripts/sync-icons.mjs 的 REGISTRY，對照基準 4.6。 → 每個圖示的意思一字不差；沒有一個圖示出現兩次、沒有兩個圖示代表同一件事。
    • x4 ［終端機］ 在兩端的 src/icon-data.ts 裡找 http。 → 只出現在授權聲明的註解裡；圖示資料本身沒有任何網址。
    • x5 ［終端機］ 看 apps/*/src/assets/fonts/。 → 各有 NotoSansTC-subset.woff2（約 1.6MB）與 OFL.txt。
    • x6 ［病人端］ 開發者工具 → Network，重新整理。 → 字型由 localhost 載入，沒有任何 fonts.googleapis.com 一類的請求。

    14.2 · 病人端首頁三區（FR-P14、驗收 2）🖥 📱¶

    用一台已放上床位、已指派病人的平板（開發時就是瀏覽器開 http://localhost:5174/?serial=…&key=…）。 一綁定就會自動跳出透析前問卷，先按右上角 🏠 回首頁。

    • x7 ［病人端］ 看首頁。 → 由上而下三區、各有框線：基本資訊（🛏 床號、🕒 進度條）→ 輪播（卡片在播，不必等閒置）→ 緊急回報（🔔 我需要協助）。
    • x8 ［病人端］ 找病人姓名與病歷號。 → 首頁與輪播上都沒有。也沒有「您好」「療程時段」「開始時間」與平板序號。
    • x9 ［病人端］ 找其他功能的按鈕。 → 除了求助區、輪播卡片、以及待完成任務的圖示之外，首頁上沒有任何可以點的東西。
    • x10 ［病人端］ 看基本資訊區的床號。 → 與護理端簡易版上這台平板所在的床號相同。到簡易版把這台平板拖到另一床，30 秒內這裡跟著變。
    • x11 ［病人端］ 點有 💡 的輪播卡片。 → 展開說明，💡 換成 ✕；不動它，細節頁逾時自動退回（預設 45 秒）。臨床數值那一張照樣標「資料時間」。
    • x12 ［護理端］ 送出一筆求助、到護理端確認、再結案。每一步回病人端看基本資訊區。 → 依序出現「✈ 已通知護理站」→「👤✓ 護理師收到了」→「✓ 已處理」（或結案時填的結果摘要）。都是注意色或完成色，不是紅色。
    • x13 ［病人端］ 關掉後端（或拔網路）。 → 基本資訊區出現「📶✕ 沒有網路，需要時請按床邊呼叫鈴」；求助區改成「請按床邊呼叫鈴」。

    14.3 · 病人端任務依時點出現（FR-P15）🖥 📱¶

    時點是營運參數（系統管理 → 營運參數：「心情問卷出現時點」預設 120 分、「衛教出現時點」預設 180 分）。 測試時可暫時改成 1 分鐘，做完改回來。

    • x14 ［護理端］ 指派一位今天還沒填過問卷的病人。［病人端］ 看平板。 → 透析前問卷自動以全螢幕出現：頂列是 📋、圓點、🏠；中間一題；底列 ‹ ›。
    • x15 ［病人端］ 點一個選項。 → 單選題點了就自動到下一題。選項是大按鈕：「沒有」是空心圓，程度選項用長條數（第幾級亮幾格），複選題是核取框。
    • x16 ［病人端］ 在第 3 題按 🏠。 → 回首頁；基本資訊區多一個 📋 圖示（注意色框）。等一會兒它不會再自己跳出來。點 📋 接著做。
    • x17 ［病人端］ 在任務畫面上什麼都不按，等閒置門檻（預設 60 秒）。 → 自動回首頁。
    • x18 ［病人端］ 做到最後一頁（補充說明），按送出。 → 回首頁，基本資訊區出現「✓ 已送出」（8 秒後消失）；📋 圖示不見；問卷不會再立刻跳出來一次。
    • x19 ［病人端］ 離線時填完送出。 → 顯示「已存在平板，有網路時會自動送出」，基本資訊區有 ⌛ 加筆數；恢復連線後自動送出。
    • x20 ［病人端］ 等到心情問卷的時點。 → 心情問卷自動出現：每題五個表情（很不好～很好），點了就下一題；最後一頁選填，送出後回首頁說「謝謝您」。
    • x21 ［病人端］ 等到衛教的時點。 → 衛教自動出現。有護理師核可過的內容時，一篇一頁、內文分頁不捲動（‹ › 換頁），最後一頁主按鈕是 ✓（看完了），「僅供參考」一類的標示留著；接著小測驗一題一頁。
    • x22 ［病人端］ 做完小測驗。 → 結果頁：大字「答對幾／幾」加一排 ✓ ✕；按 › 逐題看答錯的說明（✕ 您選的、✓ 正確的、解說）。完成後衛教圖示不再出現。
    • x23 ［病人端］ 按求助區。 → 第一頁：類別圖示格，臨床與非臨床各一個框（橫式並排、直式上下）。第二頁：選了的類別加三顆「有多急」大按鈕，點了就送出。選「其他」時多一格說明。
    • x24 ［病人端］ 在任務畫面找求助區。 → 在，位置與大小和首頁一模一樣。

    14.4 · 不捲動、求助區不被蓋住（驗收 1、6）📱¶

    目標平板型號未定（0930 已確定 10 吋，CSS 尺寸就是下面這兩個，見基準 4.10）。用瀏覽器開發者工具的裝置模式，設 1280×800 與 800×1280 各做一次；型號確定後在實機上重做（迭代 14.5 分冊 x150）。

    • x25 ［病人端］ 首頁、問卷每一題、心情每一題、衛教（含分頁與結果）、求助兩頁，兩個方向各截一張。 → 沒有任何一張出現捲軸，也沒有字被切掉。
    • x26 ［病人端］ 在 Console 貼 document.querySelector('.app-content').scrollHeight === document.querySelector('.app-content').clientHeight，逐頁跑。 → 每一頁都是 true。
    • x27 ［病人端］ 首頁輪播中、任務畫面、求助畫面各截一張，量求助區。 → 三張的求助區位置與尺寸完全相同；輪播的字沒有一個落在求助區裡（迭代 8 的 r5、r6 照做一次）。

    14.5 · 護理端簡易版：九項一步操作（FR-N15、N16、驗收 3）🖥 👥¶

    用護理站管理者登入。每次登入預設就是簡易版：左邊床位圖、右邊四個框（👤 病人、🩺 護理師、📱 平板、📣 輪播內容），整頁不捲動。

    每一項都做兩次：一次拖曳、一次不拖曳（點來源、再點目的地）。每一項做完，畫面下緣出現復原列，8 秒內按「復原」要能還原。

    • x28 看全部病人現況：不點任何東西，看床位格。 → 空床是虛線框＋🛏；治療中是 〰（折線）；待處理是 ⚠ 注意色底；緊急是 ⛔ 八角形、紅框紅底，進場閃三下後停住。平板離線、跳出固定、外殼版本過舊在平板標籤上各有圖示。
    • x29 接緊急通報：讓一台平板送出「非常緊急」的求助。 → 頂端出現一條紅框列出那一床；床位格變 ⛔。點床位格上的求助（或頂端那一條）一下即確認，床位格接著展開處理方式的圖示列。這一項沒有復原（確認時間是事實，基準 3.5）。
    • x30 結案：在展開的圖示列點一個處理方式。 → 圖示列收起，復原列寫「NN 床結案：處理方式／症狀解除…」並列出其他處理結果；8 秒內點另一個結果即改、按復原即不送出；8 秒後才真的結案。之後床位格留一個「✓ 結果」標記，點它可以補改處理結果（10 分鐘內，後端期限 60 分鐘）。
    • x31 新增病人：把 👤＋ 拖到一張有平板的空床。 → 那一床長出姓名、病歷號兩格；填好按 👤＋ 即建立、排班並指派，平板開始療程。復原＝解除指派並取消排班（病人資料留著）。
    • x32 指派平板與病人：把病人框裡的一位病人拖到有平板的空床。 → 只有有平板的空床會亮，其他地方不亮、放了也沒反應。放下即指派；那台平板在 3 秒內開始療程。
    • x33 解除指派：把床上的病人拖到「⌛ 候床」。 → 解除（手動提前解除），病人回到病人框。復原＝重新綁定同一台平板。
    • x34 排班與床位分配：把護理師框裡的一位護理師拖到床位；再用點選做一次——點護理師，連點三床，按 Esc 放回。 → 每一床都出現 🩺 名字；原本是別人的床從別人那裡拿掉。拖到已經是自己的床，就是把那一床拿掉。每一床各一條復原。
    • x35 推送輪播內容：把一張內容卡拖到某一床；另一張拖到「▦ 全部」。 → 原本在全部床位播的內容拖到某一床，變成只在那一床播（床位格出現 📣 數字）；還沒上架的同時上架。到那一床的平板看得到、別床看不到（等一分鐘或重新整理平板）。
    • x36 裝置管理：把床上的平板拖到另一床；再把一台備用平板拖到「🔒 停用」。 → 換床（那一床有平板就對調）；停用的平板鎖定並離開床位，出現在停用區裡。從停用區拖回床上＝解除停用並放上去。正在服務病人的平板不能拖進停用區。
    • x37 下機：把床上的病人拖到「⇥ 下機」。 → 復原列出現「某某 下機」；8 秒後才真的下機，這 8 秒內按復原就當作沒發生。
    • x38 鍵盤：只用 Tab、Enter、Esc 做一次「指派平板與病人」。 → 做得到（Tab 到病人、Enter 拿起、Tab 到亮起來的床位、Enter 放下）。
    • x39 👥 第三者錄影：請一位沒有參與開發的人，不給任何說明，只告訴他九項任務的名稱，逐項操作並錄影。 → 每一項都是一個動作完成（一次拖曳或一次點選；新增病人另加輸入兩格）。錄影存證，檔案不進 repo，存放位置記在演練紀錄。第一次進院前要讓至少一位護理師操作過（實作規格書 4.12 外部依賴，Q-31）。

    14.6 · 切換與權限（FR-N14）🖥¶

    • x40 ［護理端］ 簡易版右上角按「⇄ 專業版」。 → 換成 0919 的完整介面，版面與功能與之前一模一樣；右上角多一顆「⇄ 簡易版」。
    • x41 ［護理端］ 在專業版重新整理。 → 仍是專業版（同一個分頁重新整理不算重新登入）。
    • x42 ［護理端］ 登出再登入。 → 回到簡易版。
    • x43 ［護理端］ 用一般護理師登入。 → 簡易版沒有護理師框、平板框，病人框沒有 👤＋（沒有那些權限的框整個不出現，不是灰色）；其餘照常。
    • x44 ［護理端］ 用稽核角色登入。 → 直接進專業版（簡易版上沒有它的事）。
    • x45 ［護理端］ 系統管理 → 營運參數 → 「床位清單」，改成 01～10、填理由儲存。 → 11～15 床有病人正在治療時存不進去，訊息寫出是哪幾床（床拿掉了，那位病人就從床位圖上消失了）。 那幾床都空了再存：簡易版床位圖剩 10 床，11 床以後原本放著的平板回到平板框。改回 01～15。

    14.7 · 灰階截圖（驗收 5）📱¶

    • x46 ［護理端］ 準備一張床位圖同時有空床、治療中、待處理、緊急、平板離線、跳出固定、版本過舊。開發者工具 Console：document.body.style.filter = 'grayscale(1)'，截圖。 → 每一種狀態都靠形狀分得出來（虛線框、折線、三角形、八角形、斜線 Wi-Fi、盾牌、向上箭頭）。
    • x47 ［病人端］ 同樣灰階，看求助的三種狀態與離線狀態。 → ✈、👤✓、✓、📶✕ 形狀都不同。

    14.8 · 簡易版與專業版的稽核相同（驗收 4）🖥¶

    同一件事在兩邊各做一次，到專業版「稽核軌跡」並排對照。

    • x48 指派：簡易版拖病人上床；專業版「排班與指派」指派平板。 → 兩邊都是「建立當日排班」（沒有排班時）＋「裝置綁定」，說明欄格式相同。
    • x49 結案：簡易版點處理方式；專業版結案登記選同一個處理方式與結果。 → 兩筆都是「緊急通報處理完成：處理方式／處理結果」，結構化欄位（處理方式、處理結果、是否追蹤）相同。
    • x50 下機、解除、排班床位、上架：各比一次。 → 動作名稱與說明格式相同。
    • x51 簡易版才有的三件事：平板換床、輪播播放範圍、補改處理結果。 → 稽核軌跡分別是「平板換床」「調整輪播內容的播放床位」「補改求助處理結果」，說明寫出改前與改後。
