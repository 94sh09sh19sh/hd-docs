## 14.5.1 · 白底（修正紀錄 2.1、2.2）🖥 📐

- `x141` **［病人端］** 1280×800，看首頁。 → 整片白底；基本資訊區與輪播區是淺灰框、深色字；床號與可點的東西是深青色；**求助區是深紅底白字**，畫面上沒有第二個紅色的東西。
- `x142` **［病人端］** 點基本資訊區的任務圖示進透析前問卷，點一個選項，再按住另一個選項不放。 → 選中的選項是深青底白字、框線加粗；**按住時那一格明顯變暗**（放開前看得出「按到了」）。
- `x143` **［病人端］** 按「我需要協助」。 → 求助類別是白底上的淺灰格、深色圖示與字；底部求助區改成淺灰「正在填寫求助」。進「有多急」，三段的框線依序是深青、深褐、深紅，每段都有圓點數與文字。
- `x144` **［終端機］** 停掉後端，等約 11 秒。 → 求助區變成淺灰底、**深褐框與深褐字**「請按床邊呼叫鈴」，和紅色的求助按鈕一眼分得開。開回後端後恢復。

## 14.5.2 · 夜間模式在白底上（修正紀錄 2.2）🖥 📐 🌙

- `x145` **［護理端］** 把「夜間模式起始時刻」改成現在這個小時、「結束時刻」改成兩小時後。**［病人端］** 回首頁等輪播換到下一張卡。 → **輪播區整塊變暗**，連底一起變成灰色，不是只有字變黑；基本資訊區與求助區不變。版面與字級與白天相同。
- `x146` **［病人端］** 🌙 在暗的房間裡（院內透析室或關燈），平板架在床邊的高度，躺著或半躺著看首頁，白天與夜間模式各看一次。 → 白天：床號、療程進度條、輪播的字看得清楚。夜間：輪播區不刺眼、字仍讀得出來。**這一項請醫師或護理師看，並記下意見**（白底是醫師看過現場的決定，開發機驗不到）。
- `x147` **［護理端］** 把夜間模式起訖改回原值（預設 18 與 7）。 → 病人端輪播回到白底。

## 14.5.3 · 10 吋：橫放直放字一樣大（修正紀錄 2.3）🖥 📐

- `x148` **［病人端］** 1280×800 看首頁與透析前問卷，換成 800×1280 再看一次。 → 兩個方向的床號、題目、選項的字**一樣大**（直放不會小一號）；兩個方向都**沒有捲軸**，選項貼在下半部。
- `x149` **［病人端］** 800×1280，按「我需要協助」。 → 類別格不捲動，放不下才出現分頁圓點；求助區在最下面，直放時比橫放略高。
- `x150` **［病人端］** 有實機時（型號未定，Q-33）：在那台 10 吋平板上裝好外殼，重做 `x148`、`x149`。 → 與開發機上看到的相同。**若不相同**（例如畫面短邊不是 800），記下平板型號並回報，基準 4.10 要改。

## 14.5.4 · 自動化驗收 🖥

- `x151` **［終端機］** `npm run verify:iteration14-5`，再跑 `npm run check:all`、`npm run verify:iteration8`、`npm run verify:iteration14`、`npm run verify:iteration14-4` → `verify:iteration14-5` 五個步驟全部 ✓（不需要後端）；其餘全綠（求助區版面契約與迭代 14～14.4 的既有驗收沒有被動到）。
