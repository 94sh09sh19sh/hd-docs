    迭代 14.3 手動測試 — 斷線示警遍及專業版每一頁與簡易版¶

    《完整手動測試手冊》的分冊之一，對應《實作規格書》4.12.3 節與《迭代 14.3 修正紀錄》。 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 14.3 的部分。 操作端色籤（護理端／病人端／終端機／資料庫）的意思見主手冊 §00。 項次接著迭代 14.2 分冊編（x111 起；14.2 用到 x110），四冊合起來是迭代 14 的完整紀錄。

    這一冊驗兩件事：與伺服器的連線一斷，護理端專業版每一頁與簡易版都有非常醒目的警告，連線恢復後自己消失、平常不會誤報； 病人端在主機斷電（請求沒有回應、只會一直等）時，也能及時改成「請按床邊呼叫鈴」，不會停在「正在通知護理站」。

    標記 意思
    🖥 開發機 平常的開發環境。這一冊後端與前端要分開開：npm run dev:api、npm run dev:nurse、npm run dev:patient 各一個終端機；「停掉後端」就是在 dev:api 那個視窗按 Ctrl+C，「開回後端」就是再跑一次
    ⏸ 暫停後端 模擬主機斷電：停掉後端時連線會被立刻拒絕，斷電時卻是沒有回應、一直等，要用暫停才模擬得出來。netstat -ano \| findstr :3000 查出後端的 PID →「資源監視器」→ CPU 分頁 → 在那個 PID 的 node.exe 按右鍵選暫停（英文介面是 Suspend Process）；再按右鍵選繼續即恢復。容器部署時是 docker compose pause api／unpause api
    📐 目標尺寸 護理站 1366×768 與 1920×1080（基準 4.9）。瀏覽器開發者工具的裝置模擬即可

    什麼算「非常醒目」：整個畫面外圍一圈閃爍的紅框，加上一條紅底白字、帶斷線圖示的橫幅。兩樣都要有，缺一樣就不通過。

    14.3.1 · 專業版：停掉後端（修正紀錄 2.1、2.2）🖥¶

    • x111 ［護理端］ 切到專業版，停在「即時總覽」。［終端機］ 停掉後端。 → 幾秒內出現閃爍紅框，導覽列下方出現紅底白字橫幅「連線中斷」，寫著「畫面上的資料不會更新，新的求助可能看不到」。
    • x112 ［護理端］ 後端仍停著，依序點主列的「病人」「輪播內容」，再從「更多」點「稽核軌跡」。 → 每一頁都看得到紅框與橫幅；「更多」的下拉選單蓋得過橫幅、點得到。
    • x113 ［終端機］ 開回後端。［病人端］ 送出一筆求助，［護理端］ 出現求助橫幅後不要按。［終端機］ 再停掉後端。 → 紅底示警在上、求助橫幅在下；把頁面往下捲，兩者一起黏在上緣，互不遮蓋。
    • x114 ［護理端］ 後端仍停著，點畫面邊緣紅框底下的按鈕或連結。 → 點得到，紅框不擋點擊。
    • x115 ［終端機］ 開回後端。 → 最慢約 15 秒，紅框與橫幅自己消失，不必重新整理；即時總覽的資料恢復更新。

    14.3.2 · 簡易版：停掉後端（修正紀錄 2.3）🖥 📐¶

    • x116 ［護理端］ 1366×768，切回簡易版。［終端機］ 停掉後端。 → 最上面多一列紅底白字橫幅，下面依序是緊急紅框那一條、床位圖與右側四個框；整頁沒有捲軸，床位圖變矮但每一床都看得到。
    • x117 ［護理端］ 換成 1920×1080，後端仍停著。 → 同上，沒有捲軸。
    • x118 ［終端機］ 開回後端。 → 最慢約 15 秒橫幅消失，床位圖回到原本的高度。

    14.3.3 · 不會誤報（修正紀錄 2.1）🖥¶

    • x119 ［護理端］ 後端正常開著，重新整理頁面、在專業版換幾頁、切換簡易版與專業版各兩次。 → 一次都沒有閃紅。剛開頁面、串流還沒連上的那一瞬間不算斷線。

    14.3.4 · 本機沒有網路、登入失效、沒有看病人權限的帳號（修正紀錄 2.1）🖥¶

    • x120 ［護理端］ 開發者工具 → Network → 改成 Offline。 → 立即出現紅框與橫幅，標題是「這台電腦沒有網路」。改回 No throttling 後，幾秒內消失。
    • x121 ［護理端］ 開發者工具 → Application → Local Storage，把 hd.nurse.accessToken 的值改成任意字串。 → 最慢約 15 秒出現「登入已失效」，橫幅右邊有「重新登入」；點它回到登入畫面。
    • x122 ［護理端］ 用「稽核／法規（唯讀）」的帳號登入（直接進專業版的稽核軌跡）。［終端機］ 停掉後端。 → 最慢約 23 秒出現紅框與「連線中斷」橫幅。開回後端，最慢約 15 秒消失。

    14.3.5 · 減少動態效果（修正紀錄 2.2）🖥¶

    • x123 ［護理端］ 開發者工具 → Rendering → Emulate CSS media feature prefers-reduced-motion: reduce，再停掉後端。 → 紅框不閃，但一直留著；橫幅照樣出現。
    • x124 ［護理端］ 常駐總覽螢幕模式停掉後端再開回。 → 維持原本那一套（紅框閃爍、「連線中斷」橫幅），沒有出現第二條橫幅。

    14.3.6 · 病人端：主機斷電時及時改成「請按床邊呼叫鈴」（修正紀錄 2.5）🖥 ⏸¶

    • x125 ［病人端］ 綁定中、停在首頁。［終端機］ 停掉後端。 → 約 3 秒內，首頁出現黃色「沒有網路，需要時請按床邊呼叫鈴」，底部求助區改成「請按床邊呼叫鈴／目前無法通知護理站」。開回後端，幾秒內恢復「我需要協助」。
    • x126 ［終端機］ 改用暫停後端。［病人端］ 看首頁。 → 最慢約 11 秒出現同上的黃色標籤與求助區文字，不會一直停在「我需要協助」。
    • x127 ［病人端］ 繼續後端，等求助區恢復；［終端機］ 再暫停一次，［病人端］ 馬上按「我需要協助」→ 選類別 → 選有多急。 → 「正在通知護理站」最多約 8 秒就換成「沒辦法通知護理站，請按床邊呼叫鈴或出聲叫護理人員」，不會一直轉。
    • x128 ［病人端］ 後端仍暫停著，填完一份問卷送出。［終端機］ 繼續後端。 → 送出時顯示「已存在平板，有網路時會自動送出」；繼續後端之後自動補送，護理端看得到一筆（不重複）。

    14.3.7 · 自動化驗收 🖥¶

    • x129 ［終端機］ npm run verify:iteration14-3 → 六個步驟全部 ✓（不需要後端）。
    • x130 ［終端機］ npm run check:all、npm run verify:iteration14、npm run verify:iteration14-1、npm run verify:iteration14-2 → 全綠（迭代 14 到 14.2 的既有驗收沒有被動到）。
