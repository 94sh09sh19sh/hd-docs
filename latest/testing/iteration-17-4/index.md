## 17.4.1 · 基本資訊區的床號、姓名、現在時間 🎬 📐

`npm run demo:patient` 開著，用它印出來的網址開病人端（DEMO-01，配給「模擬戊」）。

- `aa97` **［病人端］** 1280×800 看首頁最上面那一框。 → 由左到右：床的圖示與 **B1**、**模擬戊**（深色粗體，比床號小一級）、療程進度條（左邊是時鐘圖示）、最右邊**現在時間**（例如 `10:42`，24 小時制，**沒有圖示**），與電腦右下角的時鐘相同。整框只有一列。
- `aa98` **［病人端］** 切到 800×1280。 → 第一列是 **B1、模擬戊、現在時間**（時間靠右），第二列是時鐘圖示與進度條。**時間沒有單獨掉到下一列**；整頁不捲動，求助按鈕的位置與大小不變。
- `aa99` **［病人端］** 開著不要碰，等到電腦時鐘換到下一分鐘。 → 半分鐘內平板上的時間跟著換，不必碰螢幕。

## 17.4.2 · 姓名只在基本資訊區 🎬

- `aa100` **［病人端］** 在首頁找「模擬戊」與他的病歷號（99 開頭的八位數，在護理端專業版的病人頁看得到）。 → 姓名**只在最上面那一框出現一次**；血壓與脫水量的圖、五個數字、跑馬燈都沒有姓名；**整個畫面找不到病歷號**。
- `aa101` **［病人端］** 點基本資訊區的任務圖示（沒有就略過），或等心情問卷自動出現。 → 任務畫面（問卷、衛教）的頂列只有任務圖示、圓點與回首頁，**沒有姓名**。按回首頁，姓名回到床號旁邊。
- `aa102` **［護理端］** 護理端開 `http://localhost:5183`，專業版 → 排班與指派，把 DEMO-01 那一列「手動解除」。 → 病人端幾秒內回到等待配對的畫面，**看不到「模擬戊」**，也看不到任何病人資訊。做完用簡易版把「模擬戊」再拖回 DEMO-01（或重開 `demo:patient`）。

## 17.4.3 · 從病床的距離看 🛏

**要等目標平板（Q-33）**。開發機的螢幕不能代替這一項。

- `aa103` **［病人端］** 平板架在床邊支架上，請一位同事躺在病床上看首頁，橫放、直放各一次。 → 床號、姓名、時間都看得清楚；時間不會被誤認成療程的開始或結束時間。看不清或會誤認的，記下是哪一個、在什麼距離，回填修正紀錄第 5 節。

## 17.4.4 · 自動化驗收 🖥

- `aa104` **［終端機］** `npm run verify:iteration17-4`（不需後端、不需資料庫）。 → 5 個步驟全部 ✓。步驟 5 會順便跑 `verify:iteration8`、`14`、`14-5`、`16`，也都要通過。
