    J-16 補 .env¶

    做什麼：notepad $cfg：HD_IMAGE_TAG 改成 <新 tag>；HD_CONFIG_DIR= 下面加 HD_EXPORT_DIR=C:\hd\hd-tablet-care\export；最後加 HOSPITAL_API_BASE_URL=、HD_SIMULATION_DEPLOYMENT=（都留空白）；存檔後打之一 J-16 的四條檢查。
