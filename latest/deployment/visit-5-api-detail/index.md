## 1. 先懂的五件事

1. **腳本做什麼**：每 3 分鐘問院方 API「今天的透析清單」，把**新的或變了的列**附加到 `<指定資料夾>\YYYY-MM.txt`（一個月一個檔），再把這一輪的結果寫進狀態檔 `fetch-status.json`；同一筆不會重複寫。v0.3.0 起只在 `fetch_hours`（07:00～23:00）裡抓，時段外不打院方 API
1. **動到的檔只有三處**：當月 txt（只附加）、狀態檔（每輪覆寫；這一趟起放在 `<指定資料夾>` 裡，本系統要讀它）、腳本資料夾的 `state\`（去重用，跟著搬到 C 槽，所以搬完不會把整天的列重寫一次）
1. **結束碼**：每跑完一支打 `$LASTEXITCODE`。`0` 成功（含「跳過」「時段外」），`1` 失敗，`2` 參數或設定錯
1. **兩個變數**：`$dir`＝指定資料夾（`…\API_Fetch\IDH_interface`），`$sf`＝腳本資料夾（`…\API_Fetch\hd-hospital-fetch`）。PowerShell 關掉就不見，重開先貼上層 AF-04 方框那一行
1. **PowerShell 開一般的**：開始 → 打 `powershell` → 直接 Enter。`Ctrl+Shift+Enter`、`Win+X` 再按 `A` 都是系統管理員。用系統管理員建的檔，排程以一般權限跑時可能寫不進去（1109 現場開成系統管理員過）

## 4. 主機不是 1109 的樣子時

AF-03 第四行是 `False`，核對路徑後確定 D 槽沒有腳本或沒有 `config.json`。這一節是從零放一次，約多 30 分鐘；學長同意才做。

1. **確認指定資料夾沒在雲端同步**：用檔案總管開 `IDH_interface`，檔案旁不能有雲朵或綠色勾勾；網址列最左邊的「開始備份」**不要按**（1109 現場那是 Windows 邀請備份桌面，表示沒在同步）。再貼 `(Get-Item -LiteralPath $dir).Attributes; Get-ChildItem -LiteralPath $dir -File | Select-Object -First 3 Name, Attributes`，出現 `ReparsePoint`、`Offline`、`Pinned`、`RecallOnDataAccess` 任何一個就**停**
1. **放腳本**：照 AF-05 下載 v0.3.0 的 zip（先不刪），然後 `Expand-Archive -LiteralPath $z -DestinationPath $new`、`Rename-Item (Join-Path $new 'hd-hospital-fetch-0.3.0') 'hd-hospital-fetch'`、`cd -LiteralPath $sf`、`Get-ChildItem -Recurse | Unblock-File`、`Copy-Item config.example.json config.json`，最後 `Remove-Item -LiteralPath $z`
1. **轉碼（只有歷史 txt 不是 UTF-8 才需要）**：`py transcode_history.py $dir` 預演（不寫檔；全部檔讀進記憶體，約每 1 GB 一分鐘，需要約合計 4.5 倍的可用記憶體）。全部是 `utf-8`（「要轉 0 個」）就跳過；有 `cp950` 才 `py transcode_history.py $dir --apply`，把最後一行「還原：…」抄下來。`混合`、`無法判斷`、「解析不出 JSON 的行」都**停**，學長決定
1. **填設定**：`notepad config.json`，`"endpoint"` 填 `values.md` 的院方位址（到 `.php` 為止），`"output_dir"`、`"status_file"`、`"fetch_hours"` 照 AF-06（範例檔已有 `fetch_hours`）
1. 接著從 AF-07 做下去
