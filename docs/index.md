## 最近三週

### [1007 — 第二次進院部分成功，院方 API 取代手動輸入（迭代 15～17）](weekly/2026-10-07.md) · 修訂中

進度：

- **1001 第二次進院：B 級部分成功**。服務在院內主機上起來、外殼 APK 建好，**護理端登不進去**（後端不放行護理端的來源）；部署手冊改寫成第十五冊，另寫之三（為什麼登不進去）、之四（主機位址改用 IP）
- **1004～1005 讀了同院 IDH 系統的程式**，使用者逐項決定：直接用院方透析清單 API、抽血數值暫定拿不到（相關功能預設關閉）、低血壓門檻與處置直接套用、主機位址改用 IP
- **1005 新版需求，同日完成迭代 15～17**：院方 API 判斷得出來的事不再要護理師做；病人平板中間改成血壓與脫水量的折線圖加一條跑馬燈；**跑馬燈內容由 AI 寫、護理師只核准**。規則引擎與管理儀表板順延為迭代 18、19
- **1006 迭代 17.1**：簡易版改成把病人拖到平板（每次透析配，床號由院方資料補）；平板停用移到系統管理；護理端改名「公告與院內衛教」「結束與離院衛教」；一條指令就看得到病人平板透析到一半的樣子
- **擋第三次進院的是 Q-27 第 12 題**（院內主機的 IP 能不能固定）；跑馬燈開啟前要請長者在床上看過速度

### [0930 — 部署改為容器、介面極簡重設計（迭代 11～14.5）](weekly/2026-09-30.md)

進度：

- **0926 依第一次進院的教訓重排四件事**：部署改為 Docker ＋ `git clone`、外殼 App 獨立 repo、AI 閘道、介面極簡，排成迭代 11～14；規則引擎與管理儀表板順延為迭代 15、16
- **迭代 11～14 完成**：開發機上從零部署、更新與回退各一次；外殼 APK 在主機上離線建置；**病人端首頁只剩三區、護理端新增簡易版並設為預設**
- **迭代 14.1～14.5**：凌晨畫面停在前一天、掃 QR code 佈建平板、簡易版修正；**斷線示警遍及每一個畫面，大量求助湧入時專業版不再被橫幅蓋掉；醫師說透析室很暗，病人端改白底；平板確定 10 吋，橫放直放字一樣大**
- **部署手冊新增第十一～十四冊**，第十四冊是第一次部署用的新手版；Q-32（對外連線）0930 已回覆，擋住第二次進院的剩 Q-27 未答的題（斷電重開誰登入、Docker Desktop 兩項設定）
