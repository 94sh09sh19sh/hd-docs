### 0922 第一次進院

**結果：C 級失敗**（部署手冊總覽第 2 節的定義：服務沒有在院內主機上跑起來，這一趟的產出是紀錄）。
完整紀錄在《[第十冊 · 第一次進院紀錄](../deployment/10-first-visit.md)》，這裡只列重點：

| 看什麼 | 結果 |
|---|---|
| 院方的要求 | 當天要求部署在容器內。「資料能不能放在容器外」有兩種讀法，**還沒釐清** |
| 現場做法 | 先手動開了一個通用的 Python 容器、在容器裡 clone，再在容器裡照第九冊做。**第九冊的指令都是在主機上下的**，在容器裡一條都不成立 |
| 更根本的一層 | 第九冊與三處容器修正**只推到另一個分支，沒有合回 `master`**。院方照預設 clone，拿到的是修正前、會在院內倒下的那一版 |
| 主機 | Windows 11 x64、時區台北、Docker Desktop 已裝且為 Linux 容器；3000 埠已被佔用；有一顆 RAM 磁碟；資料磁碟之一只剩約 4.6% |
| **電源** | **稍微碰到就會關機，要有人手動開回來，而且無人看管**。Docker Desktop 又要有人登入 Windows 才會啟動 |
| 情報蒐集表 | A 級 25 題：答到 6 題、部分 5 題、空白或未確認 14 題 |
| 現場留下的 | 一個掛著整顆 C 槽的容器與一份 clone，**下次進院第一件事是照第十冊 F-10 收掉** |
