## 怎麼算的

- 一次閱讀＝開啟一頁到離開；同一頁中途切到別的分頁再回來，仍算同一次，秒數加總
- 閱讀時間只算分頁在前景、而且兩分鐘內有捲動、點擊或按鍵的時間；一次最多算四小時
- 「我自己」＝網址加 `?me=1` 開過一次的瀏覽器，以及自動化瀏覽器（例如 Claude 操作的無頭 Chrome）；某個裝置只要標記過，它之前的紀錄也一併算成自己
- 只讀 Markdown 原檔的 AI（「問 AI」帶去的 Claude、ChatGPT）不執行網頁程式，不會被算到
- 收集的只有：隨機產生的裝置編號、頁面、開始時間、秒數；不收 IP、帳號，也不收「問 AI」裡輸入的內容
