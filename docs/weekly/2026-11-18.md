## 摘要：本週進度

- **1111 晚上開會答了三班時間（清冊 Q-34 第 2 題）**：早班 08:00～12:00、午班 13:30～17:30、晚班 18:00～22:00，每一班剛好四小時；原訂 1112 問，當天就問到
- **新的一題（Q-34 第 4 題）**：病人透析的四小時是照每班的時間，還是照個別病人的開始時間，不確定；系統 1007 起一律開始後四小時，答覆前照舊
- **病人一週三次**（一三五或二四六），班別也固定，臨時有狀況或病人決定會變動；系統本來就照當天院方資料判斷哪天、哪一班，不必加固定班表
- **下一次進院的目標改了**：同一趟把透析清單抓取腳本跑起來、本系統換版、實際上線（首波試用）；之前是只做腳本、本系統等腳本穩定之後再換
- 跟著三班時間要改的設定排成**迭代 32.1**（待排，只寫文件）：「未更新」提示時段預設 8～23 時、分班界線、四小時怎麼算；抓取腳本的時段排成《之四》T-15

### 1111 開會：三班時間與病人的班別

說明：答覆與影響在《[尚待確認事項清冊](../requirements/open-questions.md)》Q-34 的「1111 開會答覆」；要改的程式排在《[實作規格書](../requirements/implementation-spec.md)》0.10、4.32.1。

| 看什麼 | 結論 |
|---|---|
| 三班 | 早 08:00～12:00、午 13:30～17:30、晚 18:00～22:00，每一班四小時；最晚 22:00 結束，沒有跨午夜 |
| 自動建立的療程分班 | 暫代界線 12 時、17 時分得對（每班的開始時刻都落在自己那一段），不改也不會分錯班 |
| 工作量歸班 | 整點界線會把 17:00～17:30 午班的事算進晚班；要不要改成兩班空檔的中點（12:45、17:45）實作時定 |
| 「院方資料未更新」提示時段 | 現在預設 0～24 時；建議改成 8～23 時（最後一班 22:00 結束、留一小時收結束體重），護理站也可以現場手改 |
| 抓取腳本的時段 | 建議 07:00～23:00，要學長同意；`hd-hospital-fetch` 還沒有這個設定（T-15） |
| 四小時怎麼算 | 不確定照班別還是照個別開始時間（Q-34 第 4 題）；答「照班別」，結束時刻、進度條與「待確認下機」一起改 |
| 一週三次、班別固定但會變 | 與現行設計相符：哪天、哪一班照院方資料；病人之間的彙總依那一次療程的班別、不分星期（FR-S17） |
