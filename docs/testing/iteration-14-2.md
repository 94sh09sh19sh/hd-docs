## 14.2.1 · 新增病人的表單整塊看得到（修正紀錄 2.1）🖥 📐

- [ ] `x85` **［護理端］** 1366×768，把病人框的「新增病人」拖到**最上面一列**有平板的空床。
  → 格子上蓋出一塊表單：姓名、病歷號、「建立並上床」「取消」**四樣都看得到**，按鈕沒有被切掉。
- [ ] `x86` **［護理端］** 同上，改拖到**最下面一列**的空床。
  → 表單改從格子底部往上長，整塊在畫面內（最下緣沒有被螢幕切掉）。
- [ ] `x87` **［護理端］** 最下面一列、最右邊一欄的床有求助時，點開處理方式的圖示列。
  → 圖示列整塊在畫面內（往上、往左長），沒有任何一顆點不到。

## 14.2.2 · 右側框沒有被切掉的列（修正紀錄 2.2）🖥 📐

- [ ] `x88` **［護理端］** 1366×768，看右側每一個框。
  → 每個框的清單都是完整的列，**沒有只露出上半的格子**；整頁沒有捲軸。
- [ ] `x89` **［護理端］** 病人多到一頁放不下時，看框底下那一列。
  → 最前面是「‹ 1／N ›」，後面接「候床」「下機」；按 › 換下一頁，每一頁都是完整的列。
- [ ] `x90` **［護理端］** 換成 1920×1080，再看一次。
  → 每頁的格數變多（依框的大小算），仍然沒有被切掉的列。

## 14.2.3 · 停用的平板回到原位（修正紀錄 2.3）🖥

- [ ] `x91` **［護理端］** 把三台以上的平板拖到「停用」。
  → 每一台都回到平板清單裡、排在備用的後面，帶**鎖頭圖示與虛線框**；「停用」那一格高度不變，沒有蓋住清單。
- [ ] `x92` **［護理端］** 把一台停用的平板拖到有空的床。
  → 平板放上那一床，鎖頭不見（解除停用）；復原列可以一步復原。
- [ ] `x93` **［護理端］** 灰階截圖一次平板框。
  → 靠鎖頭分得出哪幾台是停用的（不是只靠顏色）。

## 14.2.4 · 簡易版新增衛教（修正紀錄 2.4）🖥

> **1005（迭代 17）起這一節的做法不再適用**：護理師不再寫衛教與公告、「一句話」拿掉（SRS FR-N17）。
> 「＋」改成點一下要 AI 寫一份草稿（只在 AI 開著時出現），草稿卡拖到床位或「全部」就是核准。現行的步驟見[迭代 17 分冊](iteration-17.md) §17.3、§17.5；下面留著對帳用。

- [ ] `x94` **［護理端］** 看輪播內容框。
  → 清單最前面有一格「＋」；框裡沒有任何內容時也有。
- [ ] `x95` **［護理端］** 把「＋」拖到「全部」。
  → 輪播內容框上長出表單：衛教（預設選中）／公告兩個圖示、目標（全部的圖示）、「＋」上架、✕ 取消、標題、卡片上的一句話。
  標題與一句話都填了「＋」才按得下去。
- [ ] `x96` **［護理端］** 填完按上架。
  → 復原列出現「新增「…」→ 全部床位」；病人端輪播（第二層開著時）出現這張卡片；專業版「輪播內容」頁看得到這一則、狀態為上架中。
- [ ] `x97` **［護理端］** 改把「＋」拖到某一床，上架一則公告，再按復原。
  → 上架時只在那一床播（格子右下的內容數加一）；復原後這一則變成「還沒上架」（沒有刪除）。
  改用點選也一樣：點「＋」、再點那一床。

## 14.2.5 · 誤下機之後排得回床上（修正紀錄 2.5）🖥

- [ ] `x98` **［護理端］** 把床上的病人拖到「下機」，**等 8 秒以上**讓它真的送出。
  → 病人回到病人框；那一床空了。
- [ ] `x99` **［護理端］** 把同一位病人拖回那一床。
  → 病人上床成功，**沒有**「該病人在此日期時段已有排班」。專業版「排班與指派」裡這位病人今天只有一筆、狀態是進行中。
- [ ] `x100` **［護理端］** 專業版「稽核軌跡」查這位病人。
  → 依序有「正常下機結束」「重新開啟當日排班」（寫明「已完成 → 已排班」）「指派平板」三筆，下機那一筆仍在。
- [ ] `x101` **［護理端］** 另一位病人：拖上床、按復原、再拖上床。
  → 第二次也成功（上床後復原取消的那一筆被重新開啟）。

## 14.2.6 · 求助類別分頁與「其他」那一框（修正紀錄 2.6）🖥 📐

- [ ] `x102` **［護理端］** 專業版「系統管理」→「功能開關」，找「病人端畫面」那一組。
  → 有「求助畫面顯示『其他』那一框（如廁、環境、口渴、機器）」，**預設關閉**；畫面上沒有任何英文識別字。
- [ ] `x103` **［病人端］** 1280×800，按「我需要協助」。
  → 只有一個框；最後一格是「其他，請有人過來一下」；十一格都完整看得到，沒有被切掉的列。
- [ ] `x104` **［病人端］** 點「其他，請有人過來一下」，選一個急迫度送出。
  → 護理端收到求助，類別是「其他，請有人過來一下」。
- [ ] `x105` **［護理端］** 開啟那個開關（填核准依據）。**［病人端］** 回首頁再按一次「我需要協助」。
  → 兩個框；放不下時分頁：頂列的圓點變多，底列有 ›，每一頁都沒有被切掉的格子。
- [ ] `x106` **［病人端］** 換成 800×1280 直式，兩種開關狀態各看一次。
  → 都沒有被切掉的格子；翻到最後一頁看得到每一格；選了類別之後按 ‹ 回到剛才那一頁。
- [ ] `x107` **［護理端］** 把開關關回去（驗收完要還原）。
  → 病人端下一次進入求助畫面又是一個框。
