# 迭代 33 手動測試 — 求助一點送出與倒數自動送出

> 《[完整手動測試手冊](manual-test-guide.md)》的分冊之一，對應《實作規格書》4.33 節。共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 33 的部分。設計與理由在《[緊急求助的語音說明](../notes/emergency-voice-help.md)》第 2 節；需求是 SRS FR-P06（1123 改寫）、附錄 C.2 的 `SX_UNSPECIFIED`、FR-M05（1123 補）。原本的求助流程在《[迭代 14 分冊](iteration-14.md)》，緊急通報與床邊前速覽在《[迭代 25 分冊](iteration-25.md)》。**與錄音無關**：這一冊沒有麥克風、沒有語音。

## 摘要

這一冊驗六件事（項次 `aq1`～`aq18`，自動化另跑 `npm run verify:iteration33` 與 `npm run verify:iteration33:api`）：

- 開關「求助倒數自動送出」預設關，關著時求助畫面與迭代 14.2 一樣；營運參數「求助倒數秒數」8 秒、5～15
- 開著時點一個類別就送出（急迫度用分派表預設），換到「已經通知護理站」，三顆急迫度照樣可以改，改的是同一則
- 沒點：類別頁上方一圈倒數，跑完送出「病人還沒選」（緊急），之後點類別更新同一則
- 倒數期間按回首頁：不送出、不算求助，只記一筆「開了又關」
- 護理端：類別欄寫「病人還沒選」、病人選了就換，示警照舊、不重響；結案照臨床組建求助處置草稿
- 工作量頁多一張「病人還沒選」每月的比例與結案結果，開關關著不出現

| 標記 | 意思 |
|---|---|
| 📱 **病人端** | 已配給今天透析中病人的平板（或開發機瀏覽器 1280×800 開病人端）；`npm run demo:patient` 最快 |
| 🖥 **護理端** | 以系統管理者登入；專業版看頂端橫幅與緊急通報頁，簡易版看紅框，另開一個分頁開總覽螢幕聽聲音 |
| 🛠 **開發機** | 遷移 `iteration33_help_countdown`（`npm run prisma:deploy -w @hd/api`，後端要先關）；看資料表用 SQLite 檢視工具開開發資料庫 |

## §33.1 開關與倒數秒數

- [ ] `aq1` **［護理端］** 🖥 系統管理 → 功能開關。 → 「病人端畫面」那一組多一列「求助倒數自動送出（類別一點就送出；沒點的話倒數跑完自動通知護理站『病人還沒選』）」，預設關閉；開啟條件寫「無；關閉時求助畫面照舊」；畫面上沒有識別字與需求編號。
- [ ] `aq2` **［病人端］** 📱 開關關著時按「我需要協助」。 → 與迭代 14.2 一模一樣：類別圖示格 → 點類別換到「有多急」三顆 → 點一顆送出、回首頁；**沒有倒數圈**、沒有「已經通知護理站」。
- [ ] `aq3` **［護理端］** 🖥 系統管理 → 營運參數。 → 多一列「求助倒數秒數」，8 秒、範圍 5～15；改成 4 或 16 存不進去。改成 10 存好之後平板重新整理，倒數那一句從 10 秒起算；改回 8。

## §33.2 點類別就送出

- [ ] `aq4` **［病人端］** 📱 開關開啟，平板重新整理後按「我需要協助」。 → 類別頁上方一個圓圈加一句「還沒選也沒關係，8 秒後會自動通知護理站」；數字每秒少 1、圓圈一秒短一格；**不轉、不閃、沒有聲音、不是紅色**；1280×800 不捲動，類別放不下照舊分頁。
- [ ] `aq5` **［病人端］** 倒數還沒跑完就點「抽筋」。 → **馬上送出**，換到「已經通知護理站」＋「抽筋」＋三顆急迫度；「不太舒服，請盡快過來」那一顆框線加粗、圓點換成勾（分派表預設是急）；倒數圈不再出現；底下的求助區寫「正在填寫求助」，回首頁後是平常送出求助之後的狀態。
- [ ] `aq6` **［護理端］** 🖥 同時看護理端。 → 點「抽筋」那一下就出現通報：專業版頂端橫幅、簡易版紅框、總覽螢幕響一聲（急），類別寫「抽筋」。
- [ ] `aq7` **［病人端］** 點「非常緊急，請馬上過來」。 → 勾換到那一顆；🖥 護理端同一則的急迫度換成緊急（頂端橫幅、緊急通報頁、總覽螢幕都是同一則，**沒有多一則、總覽螢幕不再響**）。
- [ ] `aq8` **［病人端］** 按 ‹ 回類別頁點「想吐、噁心」。 → 還是同一則：類別換成想吐、急迫度留在病人點過的緊急（不換回想吐的預設）；🖥 稽核軌跡多一筆「病人在平板上改了求助的類別或急迫度」，寫「類別：抽筋 → 想吐、噁心」。
- [ ] `aq9` **［病人端］** 新開一次求助、點「其他，請有人過來一下」。 → 立刻送出；畫面有說明框，打幾個字後底列出現送出鍵，按下去 🖥 護理端同一則的附註換成那幾個字；沒打字不出現送出鍵。

## §33.3 倒數跑完的「病人還沒選」

- [ ] `aq10` **［病人端］** 📱 按「我需要協助」之後什麼都不點，等 8 秒。 → 上方那一句換成「已經通知護理站」（綠色、有勾），類別格照留，可以接著點。
- [ ] `aq11` **［護理端］** 🖥 → 出現一則緊急通報（總覽螢幕緊急的聲音），類別欄寫「**病人還沒選**」；床邊前速覽照舊（院方量測、兩張折線圖、近期求助）；畫面上沒有 `SX_UNSPECIFIED`。稽核寫「倒數跑完自動送出：病人還沒選／非常緊急……」。
- [ ] `aq12` **［病人端］** 接著點「頭痛」。 → 換到「已經通知護理站」＋「頭痛」，急迫度是頭痛的預設（不急）；🖥 同一則的類別欄換成「頭痛」、急迫度換成一般，**沒有多一則、不重響**。🛠 那一列 `auto_raised` 是 1、`opened_at` 與 `category_chosen_at` 都有值、相差約 8 秒多。
- [ ] `aq13` **［護理端］** 再造一則「還沒選」、一直不點，護理端接手後結案（處理結果任選，「病人自行取消」以外）。 → 護理紀錄頁多一份這一則的「求助處置」草稿（照臨床組建）；之後在平板點類別 → 平板寫「護理師已經處理完這一則了，還要幫忙請再按一次『我需要協助』」，護理端那一則不變。
- [ ] `aq14` **［病人端］** 拔掉平板網路後開求助、等超過 8 秒。 → 寫「現在通知不到護理站，請按床邊呼叫鈴」，沒有倒數圈；接回網路後才送出「還沒選」（不會一直重送）。

## §33.4 開了又關

- [ ] `aq15` **［病人端］** 📱 按「我需要協助」，倒數還沒跑完就按右上角回首頁。 → 回首頁、什麼都沒送；🖥 護理端沒有通報、件數不變、沒有聲音；🛠 稽核軌跡多一筆「病人開了求助畫面又關掉（沒有送出）」，寫開了幾秒。送出之後再回首頁不另記。

## §33.5 工作量的「病人還沒選」

- [ ] `aq16` **［護理端］** 🖥 開關開著，選單 → 成效與工作量 → 工作量，期間含今天。 → 最後多一張「病人還沒選的有多少？結案時是什麼？（每月）」：每月一條，條是「還沒選」那幾則的結案結果（解除或改善、沒有改善、升級處理、非臨床需求、其他，同結案結果圖的配色）；說明寫 15% 與過半非臨床的檢討門檻；「看表格」有求助、還沒選、比例、之後點了類別、以非臨床結案、開啟到點類別九成在幾秒內；沒有個人、沒有排名、沒有紅色。
- [ ] `aq17` **［護理端］** 把開關關掉再看工作量。 → 那一張整張不出現（不是灰色）；其他圖不變。

## §33.6 自動化驗收

- [ ] `aq18` **［開發機］** 🛠 跑 `npm run verify:iteration33`（不需要後端，八步：秒數上下限、點類別送出與更新同一則、倒數跑完與失敗不重送、開了又關、系統類別與開關、病人端畫面與自帶字型、後端與護理端，加上 `check:ui`、`check:ui:design`、`check:export`、`check:egress` 與迭代 8、14、14.2 的驗收）與 `npm run verify:iteration33:api`（要 Prisma，不需要開發機的後端，八步：開關關著照舊、秒數跟著參數、還沒選、更新同一則、保留代號、開了又關、結案與草稿、工作量）。 → 兩支都全部通過。
