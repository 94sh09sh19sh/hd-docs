# 迭代 17.3 手動測試 — 所有 AI 生成內容禁用簡體字與中國大陸用語

> 《[完整手動測試手冊](manual-test-guide.md)》的分冊之一，對應《實作規格書》4.15.3 節與《[迭代 17.3 修正紀錄](../notes/iteration-17-3-fixes.md)》。
> 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 17.3 的部分。
> 操作端色籤（**護理端**／**病人端**／**終端機**／**資料庫**）的意思見主手冊 §00。
> 項次接著迭代 17.2 分冊編（`aa87` 起；17.2 用到 `aa86`），小版沿用那個迭代的字母。

**這一冊驗一件事**：AI 寫出來的內容只要含簡體字、中國大陸用語或台灣不這樣寫的字形，**系統就退回請它重寫**；連續不合格就整次失敗，不交出內容。
沒違規的照舊，一次就好。

| 標記 | 意思 |
|---|---|
| 🖥 **開發機** | 平常的開發環境，`npm run dev`，模型供應者用預設的模擬（`LLM_PROVIDER=mock`）。**這一冊大多在這裡做** |
| 🧪 **實驗室模型** | `.env` 設 `LLM_PROVIDER=lab` 接實驗室的 AI 閘道（部署手冊第十三冊），只送合成資料 |

**前置**：系統管理的「AI 輔助功能」開著（迭代 17 分冊 `aa1`）。

**怎麼讓模擬模型寫出不合格的內容**：模擬模型寫公告時，會把護理師輸入的**事由照抄進內容**。
所以在事由裡夾一個詞庫裡的詞，模擬模型每一次都會寫出那個詞，正好用來看「連續不合格」那條路。
詞從 `packages/shared/zh-tw/words.txt` 挑：**沒有 `#` 開頭的任一行，Tab 左邊那個詞**（右邊是台灣的說法）。

## 17.3.1 · 擋得住：不合格就退回重寫，連續不合格就失敗 🖥

護理端開 `http://localhost:5173`，用有「公告與院內衛教」權限的帳號登入，進**專業版 → 公告與院內衛教**。

- [ ] `aa87` **［護理端］** 公告事由輸入「10/10 停診」，按要一份。
  → 幾秒後「待核准」多一則「中心公告」，內容是事由加上模擬輸出的尾巴。**與迭代 17 時完全相同**——沒違規的不受影響。
- [ ] `aa88` **［護理端］** 公告事由輸入「10/10 停診，」再接一個從 `words.txt` 挑的詞，按要一份。
  → 那一則變成**產生失敗**，底下一行寫「連續 3 次輸出都含簡體字或中國大陸用語（最後一次：中國大陸用語「（那個詞）」→「（右邊那個說法）」），請再試一次」；旁邊有「重新生成」。
- [ ] `aa89` **［護理端］** 系統管理 → AI 呼叫紀錄。
  → 最上面三筆都是**失敗**，錯誤訊息都以「輸出含簡體字或中國大陸用語：」開頭，接著寫哪個詞改成什麼；`aa87` 那一筆是成功。
- [ ] `aa90` **［資料庫］** `npm run prisma:studio`，開 `AiInvocation`，看最新的三筆（依 `invokedAt` 排）。
  → 三筆的 `outputText` 都留著模擬模型寫的原文；**第二、三筆的 `promptText` 最後多一段**「上一次的輸出用了簡體字或中國大陸用語：…。請改用台灣的繁體中文與台灣的說法重寫，其餘要求不變。」，第一筆沒有。
- [ ] `aa91` **［護理端］** 系統管理 → 稽核軌跡，篩「AI 模型呼叫」。
  → 對應的三筆都是失敗：前兩筆寫「第 1 次（第 2 次）輸出含簡體字或中國大陸用語（…），已退回重寫」，第三筆寫「連續 3 次不合格，不交出內容」。

## 17.3.2 · 實驗室模型實際會不會寫出大陸用語 🧪

`.env` 設 `LLM_PROVIDER=lab`，照部署手冊第十三冊開好通道，`npm run dev`。**只送合成資料**——這一節只用跑馬燈的衛教主題與公告事由，本來就不帶病人資料。

- [ ] `aa92` **［護理端］** 專業版 → 公告與院內衛教，連續要 10 份衛教草稿（主題不指定，系統會輪流挑），再要 3 份公告（事由自己寫，用台灣的說法）。
  → 每一份不是進「待核准」就是「產生失敗」，不會卡在「產生中」。進了待核准的**逐字看一次**：沒有簡體字、沒有大陸用語、沒有台灣不這樣寫的字形（`packages/shared/zh-tw/variants.txt` 左邊那一欄）。
- [ ] `aa93` **［護理端］** 系統管理 → AI 呼叫紀錄，數一下這 13 份總共送了幾次、其中幾次是「輸出含簡體字或中國大陸用語」。
  → 記下來回填修正紀錄第 5 節（「沒有驗的」那一段）。**被退回的比例偏高**（例如超過三成）就要回頭看系統提示或換模型，不是放寬詞庫。
