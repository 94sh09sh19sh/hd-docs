# 迭代 14.4 手動測試 — 專業版求助橫幅湧入時不蓋掉整個畫面

> 《[完整手動測試手冊](manual-test-guide.md)》的分冊之一，對應《實作規格書》4.12.4 節與《[迭代 14.4 修正紀錄](../notes/iteration-14-4-fixes.md)》。
> 共用的環境準備、啟動與疑難排解都在主手冊，這一冊只寫迭代 14.4 的部分。
> 操作端色籤（**護理端**／**病人端**／**終端機**／**資料庫**）的意思見主手冊 §00。
> 項次接著迭代 14.3 分冊編（`x131` 起；14.3 用到 `x130`），五冊合起來是迭代 14 的完整紀錄。

**這一冊驗一件事**：大量求助同時湧入時，護理端專業版上緣的求助橫幅最多三條完整的，其餘收成一列「還有幾則」，
緊急的排在最前面、不會被收掉；**頁面本身一直看得到、按得到**。

| 標記 | 意思 |
|---|---|
| 🖥 **開發機** | 平常的開發環境，`npm run dev`。§14.4.2 要停掉後端時，改成 `dev:api`、`dev:nurse`、`dev:patient` 分開開（同 14.3 分冊） |
| 📐 **目標尺寸** | 護理站 1366×768 與 1920×1080（基準 4.9）。瀏覽器開發者工具的裝置模擬即可 |

**怎麼一次送很多則**：同一台平板送完一則求助、回首頁再按「我需要協助」就能再送，不必準備很多台。
「有多急」三顆按鈕裡，**「非常緊急，請馬上過來」**算緊急，另外兩顆算一般。

## 14.4.1 · 湧入（修正紀錄 2.1、2.2）🖥 📐

- [ ] `x131` **［護理端］** 1366×768，專業版，停在「病人」頁。**［病人端］** 連續送出 5 則一般求助（不選「非常緊急」）。
  → 上緣三條完整橫幅，第四列是「還有 2 則求助」與「全部查看」；**「病人」頁的內容仍看得到大半**，往下捲時那一塊黏在上緣，頁面照樣捲得動。
- [ ] `x132` **［病人端］** 再送 2 則「非常緊急」。
  → 兩條紅色的緊急橫幅排在最上面，第三條是最新的一般求助；最後一列「還有 4 則求助」，**不是紅色**（收掉的都是一般的）。
- [ ] `x133` **［病人端］** 再送 2 則「非常緊急」。
  → 上面三條都是紅色的緊急；最後一列變紅，寫「還有 6 則求助，其中 1 則緊急」。
- [ ] `x134` **［護理端］** 在最上面一條按「稍後」。
  → 那一條消失，第四則緊急遞補上來；最後一列變成「還有 5 則求助」，**不再是紅色**（收掉的只剩一般的）。
- [ ] `x135` **［護理端］** 按最後一列的「全部查看」。
  → 到「緊急通報」頁，九則都在清單裡；上緣的橫幅還在（「全部查看」不是「全部稍後」）。
- [ ] `x136` **［護理端］** 換成 1920×1080，依序點「即時總覽」「輪播內容」，再從「更多」點「稽核軌跡」。
  → 每一頁上緣都一樣是三條加一列；「更多」的下拉選單蓋得過橫幅、點得到。

## 14.4.2 · 別處接起來的；與斷線示警一起（修正紀錄 2.3）🖥 📐

- [ ] `x137` **［護理端］** 另開一個無痕視窗、用同一個或另一個帳號登入，停在簡易版；在上方緊急紅框點一則確認接起來。
  → 回到專業版那個視窗，幾秒內少一則：它在上面三條裡的話那一條消失、下面遞補；在收起來的那一列裡的話數字少一。不必重新整理。
- [ ] `x138` **［護理端］** 1366×768，上緣仍有三條加一列。**［終端機］** 停掉後端。
  → 最上面紅底白字「連線中斷」、下面三條求助加一列，整塊一起黏在上緣；**頁面內容仍看得到**，閃爍紅框底下的按鈕點得到。
- [ ] `x139` **［終端機］** 開回後端，等示警消失。**［護理端］** 把剩下的橫幅都按「稍後」，再到「緊急通報」頁把測試的求助都結案。
  → 上緣沒有任何橫幅；導覽列「緊急通報」旁的數字歸零。
