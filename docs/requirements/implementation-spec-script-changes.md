# 實作規格書之一：既有驗收腳本的刻意改動紀錄

上層文件：《[實作規格書](implementation-spec.md)》1.1 已完成（不重做）

> **收入方式：永久收入**（1015 起）。原本寫在實作規格書 1.1，第二次起整段搬來這裡；第一次（迭代 5）與「除此之外不得修改既有驗收腳本」的規矩仍在 1.1。
>
> **怎麼維護**：某個迭代因為需求改了、不改既有驗收腳本就跑不下去時，**在本頁最下面接一段「迭代 N 是第 X 次」**，次數連號，格式照前面幾次：一句為什麼要改，再一張「腳本／改了什麼／為什麼不算放寬」的表。
> 程式註解與修正紀錄照舊寫「實作規格書 1.1 第 X 次」，不必改寫成本頁的檔名。
