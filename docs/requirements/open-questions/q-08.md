# 尚待確認事項清冊 Q-08 實驗室 API 的取得時程與端點格式

| | |
|---|---|
| **問誰** | 實驗室 |
| **急迫度** | C |
| **卡住** | 迭代 13 的實際 AI 測試 |
| **狀態** | **已回覆（0926）**：使用規範已取得，下列第 1、2、4、5 題有答案；第 3、6 題與繁中表現在實測時補。**0927**：照規範寫的 AI 閘道已完成並在開發機上以假推論端點實測（迭代 13），實驗室上的實測待連線 |

**0926 回覆摘要**（連線位址、連接埠、帳號與密碼**不寫進本文件**——文件站是公開的）：

| 原問題 | 答案 |
|---|---|
| 怎麼取得、要什麼流程 | 以 SSH 連線實驗室伺服器；在指定路徑建個人資料夾，**資料與程式碼只放自己的資料夾**；建個人容器，**所有工作與套件都在容器內** |
| 端點格式 | Ollama（原生介面與 OpenAI 相容介面兩種）；規範要求**以 LangChain 呼叫**，建議以設定檔管理模型與參數 |
| 可用模型 | 以 Ollama 的清單指令在容器外查詢；**只能呼叫、不能管理**，要新模型需聯絡學長姐 |
| 伺服器在哪 | 實驗室內網，校外無法直連，必須先登入實驗室伺服器再轉連。**院外**，因此仍只能送合成資料 |
| 用量限制 | 無明文額度；第一次回應慢是模型載入中，一直慢可能是別人在用大型模型 |

**這個答案改變了什麼**：本系統多一個照規範寫的 AI 閘道（部署規範第 5 章、FR-S13）。**仍待補**：使用期限、資料是否被留存（第 5 題的後半）、各模型的繁體中文表現。

**背景（0909）**

正式部署前的過渡期要用實驗室 API 開發與測試，目前尚未取得。

**具體要問的**

1. 什麼時候可以拿到？需要什麼申請流程？
2. 端點格式是哪一種相容規格？認證方式為何？
3. 有沒有用量或速率限制？超過會怎樣？
4. 可用的模型有哪些？繁體中文能力如何？
5. 這個 API 的伺服器在哪裡？資料會不會被留存或用於訓練？
6. 有沒有使用期限？到期後是否需要重新申請？

**現況／暫代做法**

`MockLlmProvider` 讓所有 AI 功能可先開發與驗收，不必等這個答案。**取得後也只能送合成資料**（實驗室 API 在院外，見 Q-06）。
