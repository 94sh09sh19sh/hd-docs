# 尚待確認事項清冊 Q-15 護理師班表的現行格式

上層文件：《[尚待確認事項清冊](../open-questions.md)》第 5 章

| | |
|---|---|
| **問誰** | 護理長 |
| **急迫度** | D |
| **卡住** | 迭代 5 的班表匯入功能（已暫代） |
| **狀態** | 待提出 |

**背景**

系統目前只有病人排班，沒有護理師班表。要協助排班就得先把現行班表搬進來，而搬進來的第一步是知道它長什麼樣。

**具體要問的**

1. 現在的班表是紙本、Excel，還是醫院既有的排班系統？能不能給一份實際範例（可去識別化）？
2. 班別怎麼分（早、中、晚，還是別的分法）？每班的起訖時間？
3. 班表多久排一次？誰排？排好之後怎麼公告？
4. 除了「誰上哪一班」，班表上還有沒有記別的（負責床位、職務分工、代班註記）？
5. 臨時調動現在怎麼處理？誰決定？有沒有留紀錄？
6. 護理佐理員或其他職類要不要一起納入班表？
7. 一個班次通常幾位護理師顧幾床？床位分配的原則是什麼（固定分區、輪流、依病人狀況）？

**現況／暫代做法**

**0911 已實作**：班別先採透析中心常見的三班制（白班 07:00–15:00、小夜班 15:00–23:00、大夜班 23:00–07:00），但**起訖時間逐筆存在班表列上、可個別調整**，不由班別反推——跨日班與臨時調整都靠這兩欄。

匯入先收最小欄位集的 CSV（工作 ID、日期、班別、開始時間、結束時間、負責床位、備註），整批全有或全無：格式、查無此人、與既有班次重複、違反勞動條件，任一關不過都整批退回並逐列說明原因。拿到實際格式後改走 FR-S05 的欄位對應設定（迭代 6），現在這套檢查邏輯可原樣沿用。

第 5 題的臨時調動已做出**申請與核示**的部分（請假、換班）；第 7 題的床位分配已可逐床指派，並擋下「同一班次同一張床指派給兩個人」。

~~⚠️ FR-M03 的「候補人選排序」**刻意不在本迭代**：依技能標記、連續工時、近期負荷排序屬 L3 個人層級資料，須先通過《[資料庫使用規範](../database-policy.md)》11.3 的啟用流程（護理部書面同意＋計分規則公告＋觀察期），見 [Q-04](q-04.md)。~~ **1010 迭代 19 已實作**：依相同技能標記、近 7 天時數、接班後連續時數排，違反勞動條件的不在建議裡；個人層級的開關開著才出現，每次查看都留紀錄。
