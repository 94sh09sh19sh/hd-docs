# 尚待確認事項清冊 Q-03 三項功能的規則門檻值與所依據的 protocol 條文

| **急迫度** | B |
| **卡住** | ~~迭代 7~~ 迭代 18 的啟用（FR-R02）。規則引擎本身不受阻，**1010 已完成** |
| **狀態** | 待提出。**1005 使用者決定**：低血壓門檻直接套用同院 IDH 系統的門檻 |

**背景**

規則引擎的形態是「某個數值或次數超過門檻就標註」。門檻值就是臨床判斷本身，**開發端訂它等於在做醫療決策**，因此必須由臨床端書面提供，且系統要記錄依據出處。

**不確認的後果**

規則寫不出來。就算硬寫，那個門檻是開發端猜的，一旦出事無法辯護。

**具體要問的**

| 功能 | 要問到的具體數字 |
|---|---|
| FR-P03 風險分層 | 透析間期體重增幅超過多少（公斤或理想體重百分比）算需要留意？透析前血壓低於多少要標註？要看幾次歷史紀錄？ |
| FR-P05 療程中預警 | 同一病人在過去幾次療程的同一時段回報過同一症狀，才值得提前提醒？「同一時段」的容許範圍是幾分鐘？ |
| FR-N06 劑量調整參考 | 現行的 Hb／EPO 調整 protocol 是哪一份文件？能否提供正本？調整級距與禁忌條件為何？ |
| 三項共通 | 這些門檻的依據是院內共識、學會指引，還是文獻？請提供可引用的出處 |
| 三項共通 | 誰有權修改門檻值？改了之後要不要重新走一次確認？ |

**額外要問的兩題（關於誤報）**

1. 這三項功能誤報（沒事卻提醒）與漏報（有事卻沒提醒）之間，臨床上更能接受哪一種？門檻要往寬還是往嚴設？
2. 提醒的呈現位置與頻率有沒有上限？例如一個班次最多幾則，避免變成雜訊被無視。

**現況／暫代做法**

`rule_versions` 資料表設有「書面依據出處」欄位，**未填該欄位的規則版本無法標為生效**。無依據時規則只能在合成資料模式下執行。

**1004 線索（同院 IDH 系統程式，不是院方答覆）**

同院另一套系統用的低血壓門檻（詳見《[同院 IDH 系統參考調查](../../notes/idh-reference-survey.md#62-低血壓的判定與門檻對-q-03)》6.2 節）：

| 用途 | 規則 |
|---|---|
| 疑似低血壓 | 任一筆 SBP ≤ 90，或比前一筆掉超過 20 mmHg |
| 判定過去某次透析有低血壓 | 開始 SBP < 160 用 90、≥ 160 用 100 當門檻 |
| 預測模型警示 | 機率 ≥ 0.85 |

它補不上本題要的「書面依據出處」，只能當成問醫師時的起點。**帶去問時要講明這是另一個團隊的選擇**，不是本系統的提案，也不是院方 protocol。

**1005 使用者決定：低血壓門檻直接套用**

上表的門檻由使用者決定直接採用。**出處**：院內同一處已部署的透析中低血壓（IDH）預警系統（成大版）程式——「疑似低血壓」取自它的交班回饋表，「過去某次透析有低血壓」取自它的預測模型判定。細節見《[同院 IDH 系統參考調查](../../notes/idh-reference-survey.md#62-低血壓的判定與門檻對-q-03)》6.2 節。

**1010 迭代 18：六條規則以草稿寫進系統**（實作規格書 3.6 的表）。兩條收縮壓相關的（RISK-HYPO-01、ALERT-HYPO-01）門檻照上表、出處照上面那段寫，所以**標得了生效**；能不能拿另一套系統的程式當書面依據，由標為生效的人判斷（參考調查 9.2 第 2 項的建議是不能）。其餘四條（體重增幅、同一時段的不舒服、血紅素、Kt/V 推估）的門檻是**開發端的示範值**、出處空著，標不了生效，只對合成資料病人執行；劑量調整參考的條文是寫明「不是院方 protocol」的示範字。

**1010 迭代 18.1：四條沒有出處的規則換成開發端依文獻查的建議值**（使用者指示「先去查最適合的值，下週放在週報問醫生」）。仍寫在備註、**不填進書面依據出處**，照樣標不了生效：

| 規則 | 建議值 | 依據（細節與出處見《[迭代 18.1 修正紀錄](../../notes/iteration-18-1-fixes.md)》第 3 節） |
|---|---|---|
| RISK-IDWG-01 體重增幅 | 理想體重的 4.0%；上一次結束體重往前找 3 天 | 文獻常引用上限 4～4.5%（KDOQI）；巴西追蹤研究以 4% 分界；日本透析醫學會間隔一天 3%、間隔兩天 5% |
| ALERT-SYM-01 同一時段的不舒服 | 近 6 次中至少 2 次、前後 30 分鐘 | 沒有文獻直接訂；比照透析中低血壓「三成以上的療程」（Flythe 等，2015） |
| DOSE-HB-01 血紅素 | 10.0～11.5 g/dL、35 天內 | KDIGO 腎性貧血指引（2012；2026 更新版維持 11.5）；透析病人至少每月驗一次 |
| ADEQ-KTV-01 Kt/V 推估 | 低於 1.20、至少 3 次、取最近 6 次（沒變） | KDOQI 適足性指引（2015）：目標 1.4、最低 1.2 |

**1014 週報請醫師決定的五件事**：體重增幅要不要分間隔一天／兩天兩條；同一時段的不舒服兩週兩次夠不夠、要不要只看某幾種；血紅素上限用 11.5 還是院內的數字（附 protocol 正本）；Kt/V 提醒用 1.2 還是 1.4、院內多久驗一次；兩條收縮壓規則的回看天數與次數（開發端暫定）。

**答覆來了怎麼做**：系統管理「判斷規則」→ 那一條規則「以此版為底建立新版本」→ 填門檻、書面依據出處（劑量調整參考另貼 protocol 條文原文）→「標為生效」。舊版本與它的執行紀錄照樣留著。本題「具體要問的」那張表與兩題誤報題照舊要問；要帶去的材料多一樣：系統管理「判斷規則」那一頁，逐條讓醫師看門檻與文字範本。
