# 尚待確認事項清冊 Q-21 對外報表的核准角色

上層文件：《[尚待確認事項清冊](../open-questions.md)》第 5 章

| | |
|---|---|
| **問誰** | 護理部、資訊室 |
| **急迫度** | D |
| **卡住** | 迭代 8 的 FR-X03 |
| **狀態** | 待提出 |

**背景**

新增任務一之(4) 要讓外部機構判斷團隊實力，這與「資料不出醫院網路」直接衝突。解法是所有要離開院內的數字都必須經由對外報表模組產生，且需核准。

**具體要問的**

1. 誰有權核准資料離開院內？護理部主管加資訊室，還是要到院長室層級？
2. 醫院有沒有既有的資料釋出審查流程要接上？
3. 開發端設的門檻（只輸出聚合值、樣本數少於 5 的分組不呈現、時間粒度最細到日、不含姓名病歷號床號工作 ID）夠嗎？
4. 對外提供可操作的展示環境（獨立機器、資料全為合成）需不需要另外核准？
5. 給政府訪視與給外部公司的資料，審查標準要不要分開？

**1010 現況（迭代 19 完成）**：對外報表做好了，第 3 題的門檻全照開發端的設定做（產生時就排除，不是畫面遮蔽）。**核准角色暫由護理長與系統管理者擔任，產生的人不能核准自己的**；答覆回來後改權限設定即可。第 4 題的展示環境用 `npm run showcase` 在另一台機器上建，資料全由電腦產生、與醫院沒有連線，建立與銷毀都留紀錄。「對外報表」那一頁預設關閉，答覆後再開。
