# 尚待確認事項清冊 Q-25 事件記錄快速範本的事件類型與欄位

上層文件：《[尚待確認事項清冊](../open-questions.md)》第 5 章

| | |
|---|---|
| **問誰** | 護理部 |
| **急迫度** | D |
| **卡住** | 迭代 4 的 FR-N04（已用暫定值實作） |
| **狀態** | 待提出。**1005**：低血壓處置已併入（`EVENT-TEMPLATES-v2`） |

**背景**

FR-N04 要求「事件當下快速點選式記錄範本」。開發端先擬了 5 種事件：病人不適處置、管路或穿刺處滲血、機器警報處理、跌倒或滑倒、其他事件，每種有 1～3 個勾選欄位，只記錄「發生了什麼、做了什麼」，不含任何判讀。

**具體要問的**

1. 這 5 種事件是透析室最常需要記錄的嗎？漏了哪些？
2. 各欄位的選項（例如「處置」的調整姿勢、測量生命徵象、通知醫師、依醫囑處置、心理安撫、持續觀察）要怎麼增減？
3. 記錄格式要不要對得上院內既有的護理記錄或病人安全事件通報系統？（本階段不做雙向寫入）
4. 跌倒這類事件院內另有通報流程嗎？系統的記錄能不能當作通報的底稿？

**現況／暫代做法**

範本放在共用常數並標版本（1005 起為 `EVENT-TEMPLATES-v2`），記錄只存欄位與選項代號加上範本版本。確認後改常數並升版即可。

**1004 線索（同院 IDH 系統程式，不是院方答覆）**：同院另一套系統的低血壓警示回饋表，處置分五類——口服藥物（Midodrine）、針劑藥物（IV Glucose）、調整透析設定（降低血流速、降低脫水量、降低透析液流速）、護理處置（頭低腳高、降低透析液溫度、沖水）、其他處理（持續觀察），每類都有「其他」，另記有無症狀、處置時間與當下血壓。本系統「病人不適處置」範本**沒有任何針對低血壓的選擇**，問第 1、2 題時可以把這份當草稿一起帶去。見《[同院 IDH 系統參考調查](../../notes/idh-reference-survey.md#63-低血壓處置的選項對-q-25)》6.3 節。

**1005 使用者決定：併入**。範本新增第六種事件「透析中低血壓處置」，升版為 `EVENT-TEMPLATES-v2`：

| 欄位 | 選項 |
|---|---|
| 有無症狀（單選） | 有症狀、無症狀 |
| 處置（複選） | 口服 Midodrine（依醫囑）、注射 IV Glucose（依醫囑）、降低血流速（依醫囑）、降低脫水量（依醫囑）、降低透析液流速（依醫囑）、頭低腳高、降低透析液溫度（依醫囑）、沖水、持續觀察、其他 |
| 處置後情形（單選） | 已緩解、部分緩解、持續觀察中、轉介或轉送 |

藥物與透析設定的選項一律帶「依醫囑」，理由同 SRS 附錄 C.3：記錄的是執行醫師的指示，不是系統建議。當下血壓與處置時間寫在補充說明。舊紀錄仍標 v1，對得回當時的欄位。第 1、2 題問的「漏了哪些、選項怎麼增減」照舊待護理部看過。
