# 尚待確認事項清冊 Q-10 常駐總覽螢幕的位置與硬體

上層文件：《[尚待確認事項清冊](../open-questions.md)》第 4 章

| | |
|---|---|
| **問誰** | 護理部（位置）、資訊室（硬體） |
| **急迫度** | C |
| **卡住** | 迭代 3 的實機驗收（FR-N12） |
| **狀態** | 待提出 |

**背景**

因為所有資料不出醫院網路，**不做推播通知**。護理端的即時通知改用院內 SSE 長連線加音效提示，而這需要一台**不進入休眠、持續顯示總覽的固定螢幕**。推播沒了以後，這台螢幕是唯一保證通報被看見的地方，屬於部署必要條件而非選配。

**不確認的後果**

通報可能沒人看到。這是本次前提變更帶來的最大單一風險。

**具體要問的**

1. 護理站有沒有適合放這台螢幕的位置？從哪些工作位置看得到？
2. 螢幕尺寸與距離大概是多少？（決定字級與版面設計）
3. 硬體用現成的工作站接一台螢幕，還是額外配一台？可否用其中一台平板？
4. 音效提示在治療區會不會吵到病人？音量與提示方式有沒有限制（例如只在護理站發聲）？
5. 這台螢幕需不需要納入 MDM 管理？
6. 夜班時要不要降低亮度或改變顯示方式？
7. 螢幕上會出現病人姓名與床號。護理站的位置有沒有訪客會經過、需不需要遮蔽？

**現況／暫代做法**

以護理端的一個獨立路由實作，特徵為不休眠、大字級、音效提示、斷線示警與自動重連。開發階段可用任一台螢幕驗收，實機位置確認後再調整字級與版面。
