### 1.1 出題原則（1111 使用者定）

- **已知的事不再問**：主機只有一個 Windows 帳號（使用者）、開機要輸入 Windows 登入密碼、登入後開管理員權限不必再輸入密碼、主機預設不關機、Python 3.13（第三次、第四次進院已知），這些不再出現在清單
- **人與權限的事不列題**：誰維護、誰能改、留多久、誰讀得到、Windows 權限、要不要報備，一律是「醫師或學長同意就可以」；醫師已授權學長決定 API 的事，學長說了算。學長與使用者都會畢業，問「誰負責」到時沒人會在意
- **能給處理方法的，給選項與建議**：讓學長選，不出開放題
- 學長說過的事（聊天或現場）先查《之二之一》與私人紀錄，查得到就不問

**K-2 的估算**

| 看什麼 | 數字 |
|---|---|
| D 槽剩餘 | 0922 第一次進院 38.46 GB（共 840.6 GB，《[第十冊](../deployment/10-first-visit.md)》）→ 1109 第四次進院 13.0 GB（共 840 GB）；兩次的 C、D 總容量相同，推定是同一台。48 天少 25.5 GB |
| 這段期間搬進來的（一次性） | 學長把兩支腳本與它們抓的檔搬進 `API_Fetch`（1111 使用者確認）。透析清單月份檔 **7.7 GB**（2024-12～2026-11，約兩年；舊腳本每 3～7 分鐘把整天清單寫一次，所以大）。`hb` 的 `Hb_API_Fetch` 沒量過，照程式估：資料期間跟透析清單差不多（設定從 2024-01-01 起），但同一筆檢驗只寫一次（內容簽章去重），每筆約 2 KB，兩年估**數十 MB**，可略 |
| 其他東西的消耗 | 25.5 GB 扣掉搬進來的約 7.7 GB，剩約 17.8 GB，**約每天 0.37 GB**（不是抓取腳本） |
| 兩支腳本之後的增長 | 透析清單只寫新的或變了的列，一天約 700 列、每列約 450 位元組（1029 探測 601 列 270,647 位元組），每天不到 1 MB；`hb` 只寫新的檢驗，每月幾 MB。合計每月不到 0.1 GB，跟舊腳本的每月最多 1.28 GB 差很多 |
| 還能撐多久 | 13.0 GB ÷ 每天約 0.37 GB ≈ **35 天，約 12 月 14 日**（從 1111 算剩約 33 天） |
| 不確定的地方 | 只有兩個時間點；0922 時 D 槽上若已有舊 IDH 系統的檔（1109 學長刪掉的那些），實際消耗會更快、滿得更早；下一次進院再看一次 D 槽剩餘與 `Hb_API_Fetch` 的大小 |
| 結論 | 吃掉 D 槽的是 D 槽上別的東西（D 槽也放了正在同步的 OneDrive），不是抓取腳本；但腳本與資料在 D 槽，一滿就一起寫不進 |

## 6. C. 新腳本和原本不一樣的地方

學長說「跟原本的 `.py` 一樣的方式存下來」。下表列出原本（成大版）的做法跟開發端建議不一樣的、還沒答的每一處；C-0、C-5、C-9、C-10、C-11、C-14 已答，**C-16 1114 學長答不用**（《之二之一》第 3.6 節）。其餘都已照建議做進 v0.1.0，學長沒有異議就不必回；要改的請回那一列的題號。

| # | 哪一處 | 原本（成大版） | 開發端建議（v0.1.0 已照做） | 會影響誰 |
|---|---|---|---|---|
| C-1 | 什麼時候抓 | 有人開儀表板、而且分鐘數是 3 的倍數時 | 固定頻率（已定）；只在 07:00～23:00 抓（F-4、F-6，v0.3.0） | — |
| C-2 | 逾時與重試 | 都沒有 | 30 秒逾時、重試 3 次 | 不影響檔 |
| C-3 | 同時只跑一次 | 沒有 | 上一輪還沒跑完就跳過這一輪 | 不影響檔 |
| C-4 | 「今天」怎麼算 | 照機器的時間 | 固定 +08:00；主機本來就設 +08 的話結果一樣 | 不影響檔 |
| C-6 | 時間戳 | `Date: YYYY-MM-DD HH:MM:SS` 一行 | 跟原本一樣 | — |
| C-7 | 去掉開頭的 `<meta>` | 用 `strip` 逐字刪 | 從第一個 `{` 開始；現在的回應兩種做法結果一樣 | 不影響檔 |
| C-8 | 抓到空資料 | 照樣附加留底 | 照原本，讀檔的人才知道「有抓、只是沒資料」 | 本系統判斷資料多舊 |
| C-12 | 寫在哪 | 執行時的目前目錄 | 用設定檔指定 | 不影響檔 |
| C-13 | 主控台 | 印出整包回應（全中心的姓名、病歷號） | 只印成功、筆數、失敗原因 | 個資 |
| C-15 | 端點 | 寫死在程式裡 | 寫在設定檔，斗六搬過來時只改設定 | 不影響檔 |
