# 院方 API 的四種抓取方式之二之二：給學長的問題（簡易版）

給學長直接作答用。每題為什麼要問、估算與細節在補充版《[之二：1108 給學長的問題清單](hospital-api-fetch-methods-questions.md)》，題號相同。

**回法**：題號＋選項就好，例如「K-2 ①、K-7 要」。標「建議」的是這邊的預設，沒意見就照建議。

---

## 1. 下一次進院前要答（5 題）

| # | 問題 | 選項 |
|---|---|---|
| K-1 | 指定資料夾裡的月份檔，是從正式在用的那台 IDH 主機搬過來的嗎？ | 是／不是（不是的話，另一邊有沒有程式還在寫？） |
| K-2 | D 槽估計 12 月 14 日左右會滿（C 槽剩 763 GB）。腳本與資料要搬到 C 槽嗎？ | ① 整個 `API_Fetch` 搬到 `C:\API_Fetch\`（建議）② 留 D 槽，清掉 D 槽用不到的東西 ③ 不動 |
| K-7 | 1109 主機閒置約 5 分鐘就鎖定，當時畫面上有第二個滑鼠游標在動，像是醫師在遠端。要跟醫師說嗎？ | 要／不用（排程照跑，不影響抓取） |
| W-6 | 去重的鍵用「病歷號＋透析開始時間＋紀錄時間」，任何一欄變了就再寫一次。留底寫法選哪個？ | ① 一段 `Date:`＋JSON，只放新的或變了的列（建議）② 一列寫一行 |
| A-5 | `hb_online_v2.py`（檢驗資料）也由這邊改寫、裝排程嗎？ | 要（跟透析清單分開兩支、各自排程）／不要（第 3 節就不必答） |
