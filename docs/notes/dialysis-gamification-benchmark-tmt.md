# 透析中的遊戲化之五附錄之一：連線測驗與腎臟

版本：v0.1　文件狀態：草案（2026-11-04 開立）　適用讀者：院方（護理部、社工、醫師）、FDE 工程團隊

上層文件：《[透析中的遊戲化之五附錄：第四款遊戲的篩選過程](dialysis-gamification-benchmark-sieve.md)》

## 摘要

- 連線測驗（TMT）**不是為腎臟設計的**：1944 年美軍發表的通用神經心理測驗，失智、中風、腦外傷、精神科都在用
- 腎臟領域常用它，是因為透析病人最常受損的認知領域（注意力、處理速度、執行功能）正好是它量的
- 能看出處理速度與執行功能的變化，最有用的是跟病人自己比；不能診斷、看不出原因

## 1. 不是針對腎臟

| 欄 | 內容 |
|---|---|
| 來源 | 1944 年美軍個人測驗組（Army Individual Test Battery） |
| 原本用途 | 通用的神經心理測驗 |
| 常見使用領域 | 失智、中風、腦外傷、精神科、一般老年篩檢 |
| A 部分 | 依序連 1～25 |
| B 部分（原版） | 數字、字母交替（1-A-2-B…）；本專案改成圓、方交替（主文件第 2 節） |

## 2. 為什麼腎臟領域特別用它

| # | 理由 | 依據 |
|---|---|---|
| 1 | 透析病人認知受損常見，比例高於同齡一般人 | Murray 2006：374 位高齡透析病人 73.4% 中重度受損；Liu 2023 統合分析約 51% |
| 2 | 受損型態偏血管型：主要傷注意力、處理速度、執行功能，記憶相對保留；與阿茲海默症以記憶為主不同 | CONNECT 2024 指引：注意力與處理速度受影響最重 |
| 3 | 可能的機轉：尿毒素、腦部小血管病變、貧血、透析中血壓下降造成腦部灌流不足 | 一般文獻的說法，本專案未逐篇查證 |
| 4 | 常用的整體篩檢（例如 MMSE）偏重記憶與定向感，對執行功能不敏感；TMT-B 補這一塊 | CONNECT 2024 把 TMT-B 列為整體篩檢之外的單項測驗，並指出慢性腎病病人在 TMT-B 一貫較差 |
| 5 | 透析研究有現成切點可參考 | FHN 基線分析：Trails B ≥ 300 秒定義執行功能受損（383 人中 29%）；本專案不拿來下結論（主文件第 4 節） |

## 3. 能判斷什麼

| 指標 | 量什麼 |
|---|---|
| A 用時 | 處理速度、視覺搜尋 |
| B 用時 | 執行功能：能不能在兩條規則之間切換 |
| B−A、B÷A | 扣掉手、眼速度後剩下的執行功能 |
| 跟自己比的變化 | 這個月是否比自己過去明顯變慢；本專案的主要用法 |

透析族群裡，執行功能差常被報告與這些事相關（一般文獻的方向，本專案未逐篇查證，不寫進護理端文字）：

- 自我管理變差：限水、服藥、飲食控制
- 跌倒、住院、死亡風險較高
- 衛教與醫療決策可能需要家屬多協助

## 4. 不能判斷什麼

- **不能診斷失智或認知障礙**：只是單項篩檢指標，確診要完整評估
- **看不出原因**：變慢可能來自認知退化，也可能是視力、手抖、疲倦、憂鬱、剛透析完、不熟平板
- **透析中測的分數本來就會偏差**（主文件第 5 節）：護理端只寫事實陳述，不寫「疑似認知退化」（FR-R04）
