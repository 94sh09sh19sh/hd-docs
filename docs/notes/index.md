# 其他文件

不屬於需求文件、進度報告、參考文件、測試手冊、部署手冊的單篇技術方案評估、決策紀錄與修正紀錄。**這些不是需求文件**，與需求文件衝突時以需求文件為準。

分成兩張表：**一般文件**是方案評估、設計基準、演練紀錄與參考調查；**小迭代文件**是非整數迭代（例如 14.1、17.2）的修正紀錄——使用者看過實際畫面或實機之後當場提出、歸在某個迭代底下處理的修正。
「本週定版」欄的意思與進度首頁相同：日期是它最後一次定版的週次，`· 修訂中` 表示這週正在改。
